# AmazingHandGUI — 需求与验收标准

本文档记录由当前实现推导出的功能需求与验收标准。每条需求都会引用实现该行为所在的源文件。

---

## 一、连接管理

### FR-CONN-1：串口选择
GUI 提供一个下拉框，列出自动检测到的串口。

| AC | 标准 |
|----|-----------|
| 1.1 | 在 Linux 上显示 `/dev/ttyACM*`、`/dev/ttyUSB*`、`/dev/ttyAMA*` 设备；若都不存在，则列出 `/dev/ttyACM0` 与 `/dev/ttyUSB0` 作为后备。 |
| 1.2 | 在 Windows 上列出 `COM1`–`COM20`。 |
| 1.3 | 默认值与 `config.yaml` 中平台相关的值一致（`/dev/ttyACM0` 或 `COM9`）。 |

### FR-CONN-2：波特率选择
一个下拉框提供可配置的波特率选项。

| AC | 标准 |
|----|-----------|
| 2.1 | 选项来自 `config.yaml` → `serial.baudrate_options`（默认 `[9600, 115200, 1000000]`）。 |
| 2.2 | 默认选中 `1000000`。 |
| 2.3 | 连接期间下拉框被禁用。 |

### FR-CONN-3：连接 / 断开
Connect 与 Disconnect 按钮管理串口连接和舵机力矩。

| AC | 标准 |
|----|-----------|
| 3.1 | Connect 打开串口，对舵机 1–8 启用力矩，禁用 Connect/端口/波特率控件，启用 Disconnect。 |
| 3.2 | Disconnect 对全部 8 个舵机禁用力矩，重新启用 Connect/端口/波特率，禁用 Disconnect。 |
| 3.3 | 连接失败会在状态栏和日志中显示错误；GUI 保持未连接状态。 |

### FR-CONN-4：启动时自动连接
GUI 在启动后 100 ms 尝试自动连接。

| AC | 标准 |
|----|-----------|
| 4.1 | 初始化期间通过 `root.after(100, …)` 调用 `connect_controller()`。 |

### FR-CONN-5：CLI 连接
CLI 通过 `--port` 和 `--baudrate` 参数连接。

| AC | 标准 |
|----|-----------|
| 5.1 | `--port` 和 `--baudrate` 覆盖默认值。 |
| 5.2 | 连接时对全部 8 个舵机启用力矩。 |
| 5.3 | 退出时禁用力矩（包括通过 `finally` 块处理 Ctrl+C 的情况）。 |
| 5.4 | `--list` **不**打开硬件连接。 |

## 二、手指控制

### FR-FING-1：四个手指控件
显示四个手指控件：Ring、Middle、Pointer、Thumb —— 每个含 2 个舵机。

| AC | 标准 |
|----|-----------|
| 1.1 | 恰好渲染 4 个 `FingerControl` 控件，其名称与 `config.yaml` 的舵机对一致：Ring (5,6)、Middle (3,4)、Pointer (1,2)、Thumb (7,8)。 |

### FR-FING-2：Auto 模式（Base + Side）
Auto 模式提供一个竖直的开合滑块和一个水平的左右滑块。

| AC | 标准 |
|----|-----------|
| 2.1 | 竖直滑块：0°（张开）到 110°（握紧）；顶部 = 握紧，底部 = 张开。 |
| 2.2 | 水平滑块：−40° 到 +40°。 |
| 2.3 | 移动任一滑块都会把插值后的位置（通过 `compute_auto_positions`）发送给两个舵机。 |

### FR-FING-3：Raw 模式
Raw 模式显示两个独立的竖直滑块（每个舵机一个）。

| AC | 标准 |
|----|-----------|
| 3.1 | 选择 Raw 会隐藏 Auto 滑块，并为每个舵机显示两个竖直滑块（−40 到 110）。 |
| 3.2 | Mimic 复选框被禁用且未勾选；Center 按钮被禁用。 |
| 3.3 | 切换模式时双向同步数值（auto ↔ raw，通过 `decompose_servo_positions`）。 |

### FR-FING-4：速度控制
每根手指都有一个速度下拉框（1–6）。

| AC | 标准 |
|----|-----------|
| 4.1 | 范围为 `speeds.min`（1）到 `speeds.max`（6），默认 `speeds.default`（3）。 |
| 4.2 | 在位置指令之前，通过 `write_goal_speed()` 逐舵机发送速度。 |

### FR-FING-5：Mimic 模式
某个从动手指上的开合变化会传播到所有启用了 Mimic 的其他手指。

| AC | 标准 |
|----|-----------|
| 5.1 | 在 A 和 B 上启用 Mimic 后，A 的开合滑块变化会反映到 B 上，反之亦然。 |
| 5.2 | Mimic 仅在 Auto 模式下生效；切换到 Raw 会将其禁用。 |

### FR-FING-6：Center 按钮
将左右偏移重置为 0°。

| AC | 标准 |
|----|-----------|
| 6.1 | 点击 Center 会把 `side_var` 设为 0 并触发位置更新。 |
| 6.2 | 在 Raw 模式下 Center 被禁用。 |

### FR-FING-7：位置滑块上的鼠标滚轮
滚轮调整位置 ±5°。

| AC | 标准 |
|----|-----------|
| 7.1 | 上滚 → +5°（握紧），下滚 → −5°（张开），并夹到限位。 |

### FR-FING-8：LED 活动指示
每根手指显示一个状态 LED。

| AC | 标准 |
|----|-----------|
| 8.1 | 运动中（moving 标志 = true）→ 以约 350 ms 间隔闪烁绿色。 |
| 8.2 | 阻塞（目标与实际位置误差 ≥ 8° 且未运动）→ 常亮红色。 |
| 8.3 | 空闲 → 灰色。 |

## 五、姿态管理

### FR-POSE-1：保存姿态
用户输入名称并保存当前 8 个舵机的位置。

| AC | 标准 |
|----|-----------|
| 1.1 | 通过 `get_positions()` 采集全部 4 根手指的位置（8 个值）。 |
| 1.2 | 保存前通过 `validate_name()` 校验名称。 |
| 1.3 | 成功时：下拉框刷新（排序），输入框清空，状态栏确认。 |
| 1.4 | 名称非法或为空时弹出错误消息框。 |

### FR-POSE-2：应用姿态
选择某个姿态并点击 Apply 会让手运动到该姿态。

| AC | 标准 |
|----|-----------|
| 2.1 | 8 个位置被应用到所有手指控件。 |
| 2.2 | 舵机位置发送到硬件。 |
| 2.3 | 根据运动距离与速度估算延时；在该延时之后记录姿态完成情况，并比较目标与实际值。 |

### FR-POSE-3：删除姿态
确认后移除所选姿态。

| AC | 标准 |
|----|-----------|
| 3.1 | 弹出是/否消息框请求确认。 |
| 3.2 | 确认后：从配置中移除姿态，保存 YAML，刷新下拉框。 |
| 3.3 | 若不再有姿态，下拉框显示 `<no poses>`。 |

### FR-POSE-4：名称校验
对名称进行校验，以防止 YAML 被破坏。

| AC | 标准 |
|----|-----------|
| 4.1 | 为空 / 仅含空白 → 拒绝。 |
| 4.2 | 超过 50 个字符 → 拒绝。 |
| 4.3 | 包含 `: { } [ ] , & * # ? \| - < > = ! % @ \` " '` → 拒绝。 |
| 4.4 | 包含控制字符（ASCII < 32）→ 拒绝。 |
| 4.5 | 首尾有空格 → 拒绝。 |

## 六、序列管理

### FR-SEQ-1：序列播放器（主窗口）
下拉框选择、Loop 复选框、Play / Pause / Stop 按钮。

| AC | 标准 |
|----|-----------|
| 1.1 | 下拉框列出所有已保存的序列（或 `<no sequences>`）。 |
| 1.2 | Loop 复选框启用连续重复播放。 |
| 1.3 | Play 在后台线程中启动序列。 |
| 1.4 | Pause 在暂停/恢复间切换；按钮文字在 "⏸ Pause" 与 "▶ Resume" 之间切换。 |
| 1.5 | Stop 设置 `stop_sequence = True`；序列线程终止。 |

### FR-SEQ-2：序列执行引擎
序列在后台线程中运行，休眠可被中断。

| AC | 标准 |
|----|-----------|
| 2.1 | 姿态步骤解析 `"pose_name:s1,s2,...,s8\|delay"` 格式。 |
| 2.2 | `SLEEP:duration` 步骤在不发送硬件指令的情况下暂停。 |
| 2.3 | 若无显式延时：自动等待 = `15.0 − (avg_speed − 1) × 2.4` 秒。 |
| 2.4 | 休眠以 0.1 s 为增量执行，每个 tick 检查停止/暂停标志。 |
| 2.5 | 在循环模式下，各次迭代之间以 0.5 s 间隔分隔。 |
| 2.6 | 未知姿态名称会被跳过并给出警告。 |
| 2.7 | 执行期间 Play/Pause/Stop 按钮切换启用/禁用状态。 |

### FR-SEQ-3：序列管理器对话框
通过 "🔧 Manage" 按钮打开的双面板对话框。

| AC | 标准 |
|----|-----------|
| 3.1 | 左侧面板：已保存序列的列表框，带 Execute、Edit、Delete 按钮。 |
| 3.2 | 双击会执行一次序列（不循环），且不关闭对话框。 |
| 3.3 | Edit 将步骤载入构建器，并预填名称字段。 |

### FR-SEQ-4：序列构建器
右侧面板，用于从姿态构建序列。

| AC | 标准 |
|----|-----------|
| 4.1 | 列出可用姿态；双击会以当前速度/延时添加一个步骤。 |
| 4.2 | 逐手指速度微调框（1–6）；"⬇ Copy from UI" 导入主窗口的速度。 |
| 4.3 | 延时输入会在姿态步骤后追加 `\|delay` 后缀。 |
| 4.4 | "⏱ Delay" 插入一个独立的 `SLEEP:Xs` 步骤。 |
| 4.5 | ↑/↓ 重排，➖ 移除，🗑 清空全部。 |
| 4.6 | "💾 Save Sequence" 校验名称、保存并刷新下拉框。 |
| 4.7 | "▶ Execute" 在不保存、不关闭对话框的情况下运行已构建的序列。 |

### FR-SEQ-5：延时输入校验
延时输入中的非法浮点值会被妥善处理。

| AC | 标准 |
|----|-----------|
| 5.1 | 非数字延时会默认为无延时（添加步骤时不带 `\|delay`）。 |
| 5.2 | 非数字 SLEEP 延时时，状态栏显示 "Invalid delay value"。 |

## 七、舵机监控

### FR-MON-1：后台遥测采集
一个守护线程以约 10 Hz 轮询全部 8 个舵机。

| AC | 标准 |
|----|-----------|
| 1.1 | 线程在每次迭代之间休眠 0.1 s。 |
| 1.2 | 每个舵机采集的指标：位置、负载、温度、电压、速度、运动标志、状态、目标。 |
| 1.3 | 读取失败时重复上一个已知值，以保持数组同步。 |
| 1.4 | 反馈数据在 `feedback_lock` 下原子地更新。 |

### FR-MON-2：图表显示
右侧面板中嵌入的 Matplotlib 图表。

| AC | 标准 |
|----|-----------|
| 2.1 | 可选指标：Position、Target vs Current、Torque、Speed、Temperature、Voltage、Moving。 |
| 2.2 | "Servos" 下拉框切换 8 条曲线中哪些可见（带 ✓ All / ✕ None）。 |
| 2.3 | 图表重绘被限流为间隔 ≥100 ms。 |
| 2.4 | 未选择指标 → 显示 "Select at least one metric" 消息。 |
| 2.5 | 无数据 → 显示 "Waiting for data..." 消息。 |

### FR-MON-3：图表模式
两种模式：Multi-Servo 与 Scope。

| AC | 标准 |
|----|-----------|
| 3.1 | Scope 模式显示一个 "Scope Servo" 选择器，用于聚焦单个舵机。 |
| 3.2 | Multi-Servo 隐藏 Scope Servo 选择器。 |

### FR-MON-4：图表缩放与平移
四个用于控制视图的滑块。

| AC | 标准 |
|----|-----------|
| 4.1 | Y-Zoom：0.2× 到 5.0×，默认 1.1×。 |
| 4.2 | Y-Pan：−3.0 到 +3.0，默认 0.0。 |
| 4.3 | Time-Zoom：可用数据的 10 % 到 100 %。 |
| 4.4 | Time-Pan：0 %（最早）到 100 %（最新）。 |
| 4.5 | 所有滑块都会触发防抖后的图表重绘。 |

### FR-MON-5：滚动模式
将图表限制为最新的 N 个数据点。

| AC | 标准 |
|----|-----------|
| 5.1 | 启用且数据超过 `max_data_points`（100）时，丢弃最旧的样本。 |
| 5.2 | 禁用滚动会保留所有已采集的数据。 |

### FR-MON-6：暂停 / 恢复 / 清空图表

| AC | 标准 |
|----|-----------|
| 6.1 | Pause 停止图表重绘；遥测采集继续。 |
| 6.2 | Clear 将所有数据数组以及缩放/平移重置为默认值。 |

### FR-MON-7：反馈面板
显示所有舵机实时遥测的网格表。

| AC | 标准 |
|----|-----------|
| 7.1 | 列：S1–S8。行：Goal、Position、Speed、Torque、Voltage、Current、Temperature、Status、Moving。 |
| 7.2 | 值的格式由 `format_feedback_value()` 决定：位置 `X.XX°`、速度 `X.X°/s`、电压 `X.XX V`、温度 `X.X °C`、电流 `X mA`、负载 `X.X %`、状态 `0xHH`、运动 `Yes/No`。 |
| 7.3 | 仅更新发生变化的单元格（差分缓存）。 |
| 7.4 | 刷新被限流为更新间隔 ≥50 ms。 |

## 九、CLI 工具

### FR-CLI-1：列出姿态与序列
`--list` 在不打开连接的情况下打印所有姿态与序列。

| AC | 标准 |
|----|-----------|
| 1.1 | 输出显示姿态数量，每个名称及其位置。 |
| 1.2 | 输出显示序列数量，每个名称及其步骤数与详情。 |
| 1.3 | 不打开任何串口连接。 |

### FR-CLI-2：应用姿态
`--pose NAME` 将一个已保存的姿态发送到硬件。

| AC | 标准 |
|----|-----------|
| 2.1 | 从配置加载位置；默认速度 3 应用于所有舵机。 |
| 2.2 | 未知姿态 → 报错 + `sys.exit(1)`。 |

### FR-CLI-3：播放序列
`--sequence NAME` 播放序列；`--loop` 重复直到 Ctrl+C。

| AC | 标准 |
|----|-----------|
| 3.1 | 速度和延时从步骤字符串解析。 |
| 3.2 | `SLEEP` 步骤在不发送硬件指令的情况下暂停。 |
| 3.3 | 无显式延时 → 自动等待 = `15.0 − (avg_speed − 1) × 2.4` 秒。 |
| 3.4 | SIGINT 设置 `stop_flag` 以优雅中断。 |
| 3.5 | 未知序列 → 报错退出。 |
| 3.6 | 空序列 → 报错退出。 |
| 3.7 | 序列中的未知姿态会被跳过并给出 WARNING。 |

### FR-CLI-4：步骤解析
`parse_step()` 处理多种格式。

| AC | 标准 |
|----|-----------|
| 4.1 | `SLEEP:2.0s` → 休眠 2.0 s。 |
| 4.2 | `open:3,3,...\|2.0s` → 姿态 "open"，带速度和 2.0 s 延时。 |
| 4.3 | `open`（裸名称）→ 使用默认速度、无延时的姿态。 |
| 4.4 | 少于 8 个速度值用 3 补齐；多出的截断。 |
| 4.5 | 时长后缀 `s` / `S` 被去除。 |

### FR-CLI-5：互斥操作
`--list`、`--pose` 和 `--sequence` 互斥。

| AC | 标准 |
|----|-----------|
| 5.1 | 传入多个操作 → 非零退出。 |
| 5.2 | 不带 `--sequence` 使用 `--loop` → 报错。 |

### FR-CLI-6：配置文件覆盖
