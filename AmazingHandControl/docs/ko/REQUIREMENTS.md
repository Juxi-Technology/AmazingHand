# AmazingHandGUI — 요구사항 및 인수 기준

이 문서는 현재 구현에서 도출한 기능 요구사항과 인수 기준을 정리합니다.
각 요구사항은 해당 동작이 구현된 소스 파일을 참조합니다.

---

## 1. 연결 관리

### FR-CONN-1: 시리얼 포트 선택
GUI는 자동 감지된 시리얼 포트를 나열하는 콤보 박스를 제공합니다.

| AC | 기준 |
|----|-----------|
| 1.1 | Linux에서는 `/dev/ttyACM*`, `/dev/ttyUSB*`, `/dev/ttyAMA*` 장치가 표시됩니다. 아무것도 없으면 `/dev/ttyACM0`과 `/dev/ttyUSB0`이 폴백으로 나열됩니다. |
| 1.2 | Windows에서는 `COM1`–`COM20`이 나열됩니다. |
| 1.3 | 기본값은 `config.yaml`의 플랫폼별 값(`/dev/ttyACM0` 또는 `COM9`)과 일치합니다. |

### FR-CONN-2: 보레이트 선택
콤보 박스가 설정 가능한 보레이트 옵션을 제공합니다.

| AC | 기준 |
|----|-----------|
| 2.1 | 옵션은 `config.yaml` → `serial.baudrate_options`에서 가져옵니다(기본 `[9600, 115200, 1000000]`). |
| 2.2 | 기본 선택값은 `1000000`입니다. |
| 2.3 | 연결 중에는 드롭다운이 비활성화됩니다. |

### FR-CONN-3: 연결 / 연결 해제
Connect와 Disconnect 버튼이 시리얼 연결과 서보 토크를 관리합니다.

| AC | 기준 |
|----|-----------|
| 3.1 | Connect는 시리얼 포트를 열고, 서보 1–8의 토크를 활성화하며, Connect/포트/보레이트 컨트롤을 비활성화하고 Disconnect를 활성화합니다. |
| 3.2 | Disconnect는 8개 서보 모두의 토크를 비활성화하고, Connect/포트/보레이트를 다시 활성화하며, Disconnect를 비활성화합니다. |
| 3.3 | 연결 실패 시 상태 표시줄과 로그에 오류가 표시되며, GUI는 연결되지 않은 상태로 유지됩니다. |

### FR-CONN-4: 시작 시 자동 연결
GUI는 실행 100 ms 후 자동으로 연결을 시도합니다.

| AC | 기준 |
|----|-----------|
| 4.1 | 초기화 중 `root.after(100, …)`를 통해 `connect_controller()`가 호출됩니다. |

### FR-CONN-5: CLI 연결
CLI는 `--port`와 `--baudrate` 인수를 통해 연결합니다.

| AC | 기준 |
|----|-----------|
| 5.1 | `--port`와 `--baudrate`는 기본값을 재정의합니다. |
| 5.2 | 연결 시 8개 서보 모두의 토크가 활성화됩니다. |
| 5.3 | 종료 시(`finally` 블록을 통한 Ctrl+C 포함) 토크가 비활성화됩니다. |
| 5.4 | `--list`는 하드웨어 연결을 **열지 않습니다**. |

## 2. 손가락 제어

### FR-FING-1: 네 개의 손가락 위젯
약지, 중지, 검지, 엄지의 네 개 손가락 컨트롤이 표시되며, 각각 서보 2개를 가집니다.

| AC | 기준 |
|----|-----------|
| 1.1 | `config.yaml`의 서보 쌍과 일치하는 이름으로 정확히 4개의 `FingerControl` 위젯이 렌더링됩니다: 약지 (5,6), 중지 (3,4), 검지 (1,2), 엄지 (7,8). |

### FR-FING-2: Auto 모드(Base + Side)
Auto 모드는 수직 닫기/열기 슬라이더와 수평 좌우 슬라이더를 제공합니다.

| AC | 기준 |
|----|-----------|
| 2.1 | 수직 슬라이더: 0°(열림) ~ 110°(닫힘); 위 = 닫힘, 아래 = 열림. |
| 2.2 | 수평 슬라이더: −40° ~ +40°. |
| 2.3 | 어느 슬라이더든 움직이면 보간된 위치가 (`compute_auto_positions`를 통해) 두 서보로 전송됩니다. |

### FR-FING-3: Raw 모드
Raw 모드는 두 개의 독립적인 수직 슬라이더(서보당 하나)를 표시합니다.

| AC | 기준 |
|----|-----------|
| 3.1 | Raw를 선택하면 Auto 슬라이더가 숨겨지고 서보당 두 개의 수직 슬라이더(−40 ~ 110)가 표시됩니다. |
| 3.2 | Mimic 체크박스가 비활성화되고 체크 해제되며, Center 버튼이 비활성화됩니다. |
| 3.3 | 모드를 전환하면 값이 양방향으로 동기화됩니다(auto ↔ raw, `decompose_servo_positions`를 통해). |

### FR-FING-4: 속도 제어
각 손가락에는 속도 콤보 박스(1–6)가 있습니다.

| AC | 기준 |
|----|-----------|
| 4.1 | 범위는 `speeds.min`(1) ~ `speeds.max`(6)이며, 기본값은 `speeds.default`(3)입니다. |
| 4.2 | 속도는 위치 명령 전에 서보별로 `write_goal_speed()`를 통해 전송됩니다. |

### FR-FING-5: Mimic 모드
Mimic 중인 손가락의 닫기/열기 변경은 Mimic이 활성화된 다른 모든 손가락으로 전파됩니다.

| AC | 기준 |
|----|-----------|
| 5.1 | A와 B에서 Mimic을 활성화하면 A의 닫기/열기 슬라이더 변경이 B에 반영되고 그 반대도 마찬가지입니다. |
| 5.2 | Mimic은 Auto 모드에서만 적용되며, Raw로 전환하면 비활성화됩니다. |

### FR-FING-6: Center 버튼
측방 오프셋을 0°로 재설정합니다.

| AC | 기준 |
|----|-----------|
| 6.1 | Center를 클릭하면 `side_var`가 0으로 설정되고 위치 갱신이 트리거됩니다. |
| 6.2 | Center는 Raw 모드에서 비활성화됩니다. |

### FR-FING-7: 위치 슬라이더의 마우스 휠
스크롤 휠로 위치를 ±5° 조정합니다.

| AC | 기준 |
|----|-----------|
| 7.1 | 위로 스크롤 → +5°(닫기), 아래로 스크롤 → −5°(열기), 한계 내로 클램프됩니다. |

### FR-FING-8: LED 활동 표시기
각 손가락은 상태 LED를 표시합니다.

| AC | 기준 |
|----|-----------|
| 8.1 | 이동 중(이동 플래그 = true) → 약 350 ms 간격으로 녹색 점멸. |
| 8.2 | 차단됨(목표 대 위치 오차 ≥ 8°이며 이동하지 않음) → 빨간색 점등. |
| 8.3 | 대기 중 → 회색. |

## 3. 키보드 제어

### FR-KEY-1: 손가락 선택
키 1–4가 활성 손가락을 선택합니다.

| AC | 기준 |
|----|-----------|
| 1.1 | 1 = 약지, 2 = 중지, 3 = 검지, 4 = 엄지. |
| 1.2 | 상태 표시줄에 선택된 손가락 이름이 표시됩니다. |

### FR-KEY-2: 방향키 이동
방향키가 선택된 손가락을 움직입니다.

| AC | 기준 |
|----|-----------|
| 2.1 | 위 = 닫기(위치 증가), 아래 = 열기(감소). |
| 2.2 | 오른쪽 = 측방 오프셋 증가, 왼쪽 = 감소. |

### FR-KEY-3: 정밀도 보조키
스텝 크기는 보조키에 따라 달라집니다.

| AC | 기준 |
|----|-----------|
| 3.1 | 보조키 없음: 1°(정밀). |
| 3.2 | Shift: 5°(일반). |
| 3.3 | Ctrl: 10°(고속). |
| 3.4 | 상태 표시줄에 모드 이름과 결과 각도가 표시됩니다. |

### FR-KEY-4: 빠른 동작

## 5. 포즈 관리

### FR-POSE-1: 포즈 저장
사용자가 이름을 입력하고 현재 8개 서보 위치를 저장합니다.

| AC | 기준 |
|----|-----------|
| 1.1 | 4개 손가락 모두의 위치(8개 값)가 `get_positions()`를 통해 캡처됩니다. |
| 1.2 | 저장 전에 `validate_name()`으로 이름이 검증됩니다. |
| 1.3 | 성공 시: 드롭다운이 (정렬되어) 갱신되고, 입력란이 비워지며, 상태 표시줄이 확인을 표시합니다. |
| 1.4 | 유효하지 않거나 빈 이름은 오류 메시지 상자를 표시합니다. |

### FR-POSE-2: 포즈 적용
포즈를 선택하고 Apply를 클릭하면 손이 해당 포즈로 이동합니다.

| AC | 기준 |
|----|-----------|
| 2.1 | 8개 위치가 모든 손가락 위젯에 적용됩니다. |
| 2.2 | 서보 위치가 하드웨어로 전송됩니다. |
| 2.3 | 지연은 이동 거리와 속도로 추정되며, 그 지연 후에 목표 대 실제를 비교하여 포즈 완료가 로깅됩니다. |

### FR-POSE-3: 포즈 삭제
확인 후 선택된 포즈를 제거합니다.

| AC | 기준 |
|----|-----------|
| 3.1 | 예/아니오 메시지 상자로 확인을 요청합니다. |
| 3.2 | 확인 시: 설정에서 포즈가 제거되고, YAML이 저장되며, 드롭다운이 갱신됩니다. |
| 3.3 | 포즈가 남아 있지 않으면 드롭다운에 `<no poses>`가 표시됩니다. |

### FR-POSE-4: 이름 검증
YAML 손상을 방지하기 위해 이름이 검증됩니다.

| AC | 기준 |
|----|-----------|
| 4.1 | 비어 있음 / 공백만 있음 → 거부. |
| 4.2 | 50자 초과 → 거부. |
| 4.3 | `: { } [ ] , & * # ? \| - < > = ! % @ \` " '` 포함 → 거부. |
| 4.4 | 제어 문자(ASCII < 32) 포함 → 거부. |
| 4.5 | 앞뒤 공백 → 거부. |

## 6. 시퀀스 관리

### FR-SEQ-1: 시퀀스 플레이어(메인 창)
드롭다운 선택, Loop 체크박스, Play / Pause / Stop 버튼.

| AC | 기준 |
|----|-----------|
| 1.1 | 드롭다운에 저장된 모든 시퀀스가 나열됩니다(또는 `<no sequences>`). |
| 1.2 | Loop 체크박스로 연속 반복을 활성화합니다. |
| 1.3 | Play는 백그라운드 스레드에서 시퀀스를 시작합니다. |
| 1.4 | Pause는 일시정지/재개를 토글하며, 버튼 텍스트가 "⏸ Pause"와 "▶ Resume" 사이에서 바뀝니다. |
| 1.5 | Stop은 `stop_sequence = True`로 설정하며, 시퀀스 스레드가 종료됩니다. |

### FR-SEQ-2: 시퀀스 실행 엔진
시퀀스는 중단 가능한 슬립을 사용하여 백그라운드 스레드에서 실행됩니다.

| AC | 기준 |
|----|-----------|
| 2.1 | 포즈 스텝은 `"pose_name:s1,s2,...,s8\|delay"` 형식을 파싱합니다. |
| 2.2 | `SLEEP:duration` 스텝은 하드웨어 명령 없이 일시정지합니다. |
| 2.3 | 명시적 지연이 없으면: 자동 대기 = `15.0 − (avg_speed − 1) × 2.4`초. |
| 2.4 | 슬립은 0.1초 단위로 실행되며 매 틱마다 중단/일시정지 플래그를 확인합니다. |
| 2.5 | 루프 모드에서는 0.5초 간격이 반복 사이를 구분합니다. |
| 2.6 | 알 수 없는 포즈 이름은 경고와 함께 건너뜁니다. |
| 2.7 | 실행 중에는 Play/Pause/Stop 버튼의 활성/비활성 상태가 전환됩니다. |

### FR-SEQ-3: 시퀀스 관리자 대화 상자
"🔧 Manage" 버튼으로 접근하는 2패널 대화 상자입니다.

| AC | 기준 |
|----|-----------|
| 3.1 | 왼쪽 패널: Execute, Edit, Delete 버튼이 있는 저장된 시퀀스 목록 상자. |
| 3.2 | 더블 클릭 시 대화 상자를 닫지 않고 시퀀스를 한 번(비루프) 실행합니다. |
| 3.3 | Edit은 스텝을 빌더에 로드하고 이름 필드를 미리 채웁니다. |

### FR-SEQ-4: 시퀀스 빌더
포즈로부터 시퀀스를 구성하는 오른쪽 패널입니다.

| AC | 기준 |
|----|-----------|
| 4.1 | 사용 가능한 포즈가 나열되며, 더블 클릭하면 현재 속도/지연으로 스텝이 추가됩니다. |
| 4.2 | 손가락별 속도 스핀박스(1–6); "⬇ Copy from UI"는 메인 창의 속도를 가져옵니다. |
| 4.3 | 지연 입력은 포즈 스텝에 `\|delay` 접미사를 추가합니다. |
| 4.4 | "⏱ Delay"는 독립적인 `SLEEP:Xs` 스텝을 삽입합니다. |
| 4.5 | ↑/↓ 순서 변경, ➖ 제거, 🗑 전체 지우기. |
| 4.6 | "💾 Save Sequence"는 이름을 검증하고, 저장하며, 드롭다운을 갱신합니다. |
| 4.7 | "▶ Execute"는 저장하거나 대화 상자를 닫지 않고 구성된 시퀀스를 실행합니다. |

### FR-SEQ-5: 지연 입력 검증
지연 입력의 잘못된 부동소수점 값은 우아하게 처리됩니다.

| AC | 기준 |
|----|-----------|
| 5.1 | 숫자가 아닌 지연은 지연 없음으로 기본 설정됩니다(`\|delay` 없이 스텝 추가). |
| 5.2 | 숫자가 아닌 SLEEP 지연은 상태 표시줄에 "Invalid delay value"를 표시합니다. |

## 7. 서보 모니터링

### FR-MON-1: 백그라운드 텔레메트리 수집
데몬 스레드가 약 10 Hz로 8개 서보를 모두 폴링합니다.

| AC | 기준 |
|----|-----------|
| 1.1 | 스레드는 반복 사이에 0.1초 동안 슬립합니다. |
| 1.2 | 서보별로 수집되는 지표: 위치, 부하, 온도, 전압, 속도, 이동 플래그, 상태, 목표. |

## 9. CLI 도구

### FR-CLI-1: 포즈와 시퀀스 나열
`--list`는 연결을 열지 않고 모든 포즈와 시퀀스를 출력합니다.

| AC | 기준 |

| 1.3 | 시리얼 연결이 열리지 않습니다. |

### FR-CLI-2: 포즈 적용
`--pose NAME`은 저장된 포즈를 하드웨어로 전송합니다.

| AC | 기준 |
|----|-----------|
| 2.1 | 위치는 설정에서 로드되며, 기본 속도 3이 모든 서보에 적용됩니다. |
| 2.2 | 알 수 없는 포즈 → 오류 + `sys.exit(1)`. |

### FR-CLI-3: 시퀀스 재생
`--sequence NAME`은 시퀀스를 재생합니다; `--loop`는 Ctrl+C까지 반복합니다.

| AC | 기준 |
|----|-----------|
| 3.1 | 속도와 지연은 스텝 문자열에서 파싱됩니다. |
| 3.2 | `SLEEP` 스텝은 하드웨어 명령 없이 일시정지합니다. |
| 3.3 | 명시적 지연이 없으면 → 자동 대기 = `15.0 − (avg_speed − 1) × 2.4`초. |
| 3.4 | SIGINT는 `stop_flag`를 설정하여 정상적으로 인터럽트합니다. |
| 3.5 | 알 수 없는 시퀀스 → 오류와 함께 종료. |
| 3.6 | 빈 시퀀스 → 오류와 함께 종료. |
| 3.7 | 시퀀스 내 알 수 없는 포즈는 WARNING과 함께 건너뜁니다. |

### FR-CLI-4: 스텝 파싱
`parse_step()`은 여러 형식을 처리합니다.

| AC | 기준 |
|----|-----------|
| 4.1 | `SLEEP:2.0s` → 2.0초 슬립. |
| 4.2 | `open:3,3,...\|2.0s` → 속도와 2.0초 지연이 있는 포즈 "open". |
| 4.3 | `open`(이름만) → 기본 속도, 지연 없음의 포즈. |
| 4.4 | 8개보다 짧은 속도는 3으로 채워지고, 더 긴 것은 잘립니다. |
| 4.5 | 기간 접미사 `s` / `S`는 제거됩니다. |

### FR-CLI-5: 상호 배타적 동작

| AC | 기준 |
|----|-----------|
| 5.1 | 여러 동작을 전달 → 0이 아닌 종료 코드. |
