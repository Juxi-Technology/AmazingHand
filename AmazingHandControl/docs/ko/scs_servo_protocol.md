## 1. 서보 통신 프로토콜

서보는 **FT-SCS 커스텀 프로토콜**을 사용합니다.

- 기본 보레이트: **1 Mbps 또는 500 kbps**
- 물리 계층: **TTL 단일 버스**
- 데이터 비트: **8**
- 패리티: **없음**
- 정지 비트: **1**
- 설정 가능한 보레이트 범위: **38 400 ~ 1 Mbps (500 k)**
- 기본 통신 주소(ID): **1**

프로토콜 레퍼런스:
[FT-SCS 커스텀 프로토콜](http://doc.feetech.cn/#/tiaozhunlujingft?srcType=FT-SCS-Protocol-41ad23fe8a244712ba160b93)

## 3. 특수 바이트 설명

---

### 3.1 서보 위상

**비트 / 가중치: 설명**

- **BIT0 (1)**: 구동 방향 위상  
  - 0: 정방향  
  - 1: 역방향
- **BIT1 (2)**: –––
- **BIT2 (4)**: –––
- **BIT3 (8)**: 속도 모드  
  - 0: 속도 = 0은 정지  
  - 1: 속도 = 0은 최대 속도
- **BIT4 (16)**: –––
- **BIT5 (32)**: PWM 위상  
  - 0: 동상  
  - 1: 반전
- **BIT6 (64)**: 전압 모드  
  - 0: 1.5 k 저전압 감지  
  - 1: 1 k 고전압 감지
- **BIT7 (128)**: –––

> 여러 비트가 동시에 설정되면 **위상 값**은 설정된 모든 비트 값의 **합**입니다.

---

### 3.2 서보 상태

**서보 상태: 0 = 정상, 1 = 오류**

**비트 / 가중치: 설명**

- **BIT0 (1)**: 전압 상태  
- **BIT1 (2)**: –––  
- **BIT2 (4)**: 온도 상태  
- **BIT3 (8)**: –––  
- **BIT4 (16)**: –––  
- **BIT5 (32)**: 부하 상태  
- **BIT6 (64)**: –––  
- **BIT7 (128)**: –––  

> 여러 오류 조건이 존재하면 **상태 값**은 해당 비트 값의 **합**입니다.  
> 예: 과전압/저전압과 과온 → status = 4 + 1 = **5**.

---

### 3.3 언로드 조건

**언로드 조건: 0 = 비활성화, 1 = 활성화**  
("Unload" = 보호를 위해 토크를 끄는 것.)

**비트 / 가중치: 설명**

- **BIT0 (1)**: 전압 보호  
- **BIT1 (2)**: –––  
- **BIT2 (4)**: 과온 보호  
- **BIT3 (8)**: –––  
- **BIT4 (16)**: –––  
- **BIT5 (32)**: 과부하 보호  
- **BIT6 (64)**: –––  
- **BIT7 (128)**: –––  

> 여러 비트가 설정되면 **언로드 조건 값**은 비트 값의 **합**입니다.  
> 예: 전압 보호 + 과온 보호 활성화 → 언로드 값 = 4 + 1 = **5**.

---

### 3.4 LED 알람 조건

**LED 알람 조건: 0 = 꺼짐, 1 = 켜짐**

**비트 / 가중치: 설명**

- **BIT0 (1)**: 전압 알람  
- **BIT1 (2)**: –––  
- **BIT2 (4)**: 과온 알람  
- **BIT3 (8)**: –––  
- **BIT4 (16)**: –––  
- **BIT5 (32)**: 과부하 알람  
- **BIT6 (64)**: –––  
- **BIT7 (128)**: –––  

> 여러 비트가 설정되면 **LED 알람 조건 값**은 비트 값의 **합**입니다.  
> 예: 전압 알람 + 과온 알람 활성화 → 알람 값 = 4 + 1 = **5**.
