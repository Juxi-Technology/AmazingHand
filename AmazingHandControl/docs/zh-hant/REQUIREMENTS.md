# AmazingHandGUI — 需求與驗收標準

本文件記錄由當前實作推導出的功能需求與驗收標準。每條需求都會引用實作該行為所在的原始碼檔案。

---

## 一、連線管理

### FR-CONN-1：序列埠選擇
GUI 提供一個下拉式選單，列出自動偵測到的序列埠。

| AC | 標準 |
|----|-----------|
| 1.1 | 在 Linux 上顯示 `/dev/ttyACM*`、`/dev/ttyUSB*`、`/dev/ttyAMA*` 裝置；若都不存在，則列出 `/dev/ttyACM0` 與 `/dev/ttyUSB0` 作為後備。 |
| 1.2 | 在 Windows 上列出 `COM1`–`COM20`。 |
| 1.3 | 預設值與 `config.yaml` 中平台相關的值一致（`/dev/ttyACM0` 或 `COM9`）。 |

### FR-CONN-2：鮑率選擇
一個下拉式選單提供可設定的鮑率選項。

| AC | 標準 |
|----|-----------|
| 2.1 | 選項來自 `config.yaml` → `serial.baudrate_options`（預設 `[9600, 115200, 1000000]`）。 |
| 2.2 | 預設選取 `1000000`。 |
| 2.3 | 連線期間下拉式選單被停用。 |

### FR-CONN-3：連線 / 中斷連線
Connect 與 Disconnect 按鈕管理序列埠連線和舵機力矩。

| AC | 標準 |
|----|-----------|
| 3.1 | Connect 開啟序列埠，對舵機 1–8 啟用力矩，停用 Connect/連接埠/鮑率控件，啟用 Disconnect。 |
| 3.2 | Disconnect 對全部 8 個舵機停用力矩，重新啟用 Connect/連接埠/鮑率，停用 Disconnect。 |
| 3.3 | 連線失敗會在狀態列和日誌中顯示錯誤；GUI 保持未連線狀態。 |

### FR-CONN-4：啟動時自動連線
GUI 在啟動後 100 ms 嘗試自動連線。

| AC | 標準 |
|----|-----------|
| 4.1 | 初始化期間透過 `root.after(100, …)` 呼叫 `connect_controller()`。 |

### FR-CONN-5：CLI 連線
CLI 透過 `--port` 和 `--baudrate` 參數連線。

| AC | 標準 |
|----|-----------|
| 5.1 | `--port` 和 `--baudrate` 覆寫預設值。 |
| 5.2 | 連線時對全部 8 個舵機啟用力矩。 |
| 5.3 | 結束時停用力矩（包括透過 `finally` 區塊處理 Ctrl+C 的情況）。 |
| 5.4 | `--list` **不**開啟硬體連線。 |

## 二、手指控制

### FR-FING-1：四個手指控件
顯示四個手指控件：Ring、Middle、Pointer、Thumb —— 每個含 2 個舵機。

| AC | 標準 |
|----|-----------|
| 1.1 | 恰好渲染 4 個 `FingerControl` 控件，其名稱與 `config.yaml` 的舵機對一致：Ring (5,6)、Middle (3,4)、Pointer (1,2)、Thumb (7,8)。 |

### FR-FING-2：Auto 模式（Base + Side）
Auto 模式提供一個垂直的開合滑桿和一個水平的左右滑桿。

| AC | 標準 |
|----|-----------|
| 2.1 | 垂直滑桿：0°（張開）到 110°（握緊）；頂部 = 握緊，底部 = 張開。 |
| 2.2 | 水平滑桿：−40° 到 +40°。 |
| 2.3 | 移動任一滑桿都會把插值後的位置（透過 `compute_auto_positions`）傳送給兩個舵機。 |

### FR-FING-3：Raw 模式
Raw 模式顯示兩個獨立的垂直滑桿（每個舵機一個）。

| AC | 標準 |
|----|-----------|
| 3.1 | 選擇 Raw 會隱藏 Auto 滑桿，並為每個舵機顯示兩個垂直滑桿（−40 到 110）。 |
| 3.2 | Mimic 核取方塊被停用且未勾選；Center 按鈕被停用。 |
| 3.3 | 切換模式時雙向同步數值（auto ↔ raw，透過 `decompose_servo_positions`）。 |

### FR-FING-4：速度控制
每根手指都有一個速度下拉式選單（1–6）。

| AC | 標準 |
|----|-----------|
| 4.1 | 範圍為 `speeds.min`（1）到 `speeds.max`（6），預設 `speeds.default`（3）。 |
| 4.2 | 在位置指令之前，透過 `write_goal_speed()` 逐舵機傳送速度。 |

### FR-FING-5：Mimic 模式
某個從動手指上的開合變化會傳播到所有啟用了 Mimic 的其他手指。

| AC | 標準 |
|----|-----------|
| 5.1 | 在 A 和 B 上啟用 Mimic 後，A 的開合滑桿變化會反映到 B 上，反之亦然。 |
| 5.2 | Mimic 僅在 Auto 模式下生效；切換到 Raw 會將其停用。 |

### FR-FING-6：Center 按鈕
將左右偏移重設為 0°。

| AC | 標準 |
|----|-----------|
| 6.1 | 點擊 Center 會把 `side_var` 設為 0 並觸發位置更新。 |
| 6.2 | 在 Raw 模式下 Center 被停用。 |

### FR-FING-7：位置滑桿上的滑鼠滾輪
滾輪調整位置 ±5°。

| AC | 標準 |
|----|-----------|
| 7.1 | 上滾 → +5°（握緊），下滾 → −5°（張開），並夾到限位。 |

### FR-FING-8：LED 活動指示
每根手指顯示一個狀態 LED。

| AC | 標準 |
|----|-----------|
| 8.1 | 運動中（moving 標誌 = true）→ 以約 350 ms 間隔閃爍綠色。 |
| 8.2 | 阻塞（目標與實際位置誤差 ≥ 8° 且未運動）→ 恆亮紅色。 |
| 8.3 | 閒置 → 灰色。 |

## 五、姿態管理

### FR-POSE-1：儲存姿態
使用者輸入名稱並儲存當前 8 個舵機的位置。

| AC | 標準 |
|----|-----------|
| 1.1 | 透過 `get_positions()` 擷取全部 4 根手指的位置（8 個值）。 |
| 1.2 | 儲存前透過 `validate_name()` 驗證名稱。 |
| 1.3 | 成功時：下拉式選單重新整理（排序），輸入框清空，狀態列確認。 |
| 1.4 | 名稱非法或為空時彈出錯誤訊息方塊。 |

### FR-POSE-2：套用姿態
選擇某個姿態並點擊 Apply 會讓手運動到該姿態。

| AC | 標準 |
|----|-----------|
| 2.1 | 8 個位置被套用到所有手指控件。 |
| 2.2 | 舵機位置傳送到硬體。 |
| 2.3 | 根據運動距離與速度估算延時；在該延時之後記錄姿態完成情況，並比較目標與實際值。 |

### FR-POSE-3：刪除姿態
確認後移除所選姿態。

| AC | 標準 |
|----|-----------|
| 3.1 | 彈出是/否訊息方塊要求確認。 |
| 3.2 | 確認後：從設定中移除姿態，儲存 YAML，重新整理下拉式選單。 |
| 3.3 | 若不再有姿態，下拉式選單顯示 `<no poses>`。 |

### FR-POSE-4：名稱驗證
對名稱進行驗證，以防止 YAML 被破壞。

| AC | 標準 |
|----|-----------|
| 4.1 | 為空 / 僅含空白 → 拒絕。 |
| 4.2 | 超過 50 個字元 → 拒絕。 |
| 4.3 | 包含 `: { } [ ] , & * # ? \| - < > = ! % @ \` " '` → 拒絕。 |
| 4.4 | 包含控制字元（ASCII < 32）→ 拒絕。 |
| 4.5 | 首尾有空格 → 拒絕。 |

## 六、序列管理

### FR-SEQ-1：序列播放器（主視窗）
下拉式選單選擇、Loop 核取方塊、Play / Pause / Stop 按鈕。

| AC | 標準 |
|----|-----------|
| 1.1 | 下拉式選單列出所有已儲存的序列（或 `<no sequences>`）。 |
| 1.2 | Loop 核取方塊啟用連續重複播放。 |
| 1.3 | Play 在背景執行緒中啟動序列。 |
| 1.4 | Pause 在暫停/恢復之間切換；按鈕文字在 "⏸ Pause" 與 "▶ Resume" 之間切換。 |
| 1.5 | Stop 設定 `stop_sequence = True`；序列執行緒終止。 |

### FR-SEQ-2：序列執行引擎
序列在背景執行緒中執行，休眠可被中斷。

| AC | 標準 |
|----|-----------|
| 2.1 | 姿態步驟解析 `"pose_name:s1,s2,...,s8\|delay"` 格式。 |
| 2.2 | `SLEEP:duration` 步驟在不傳送硬體指令的情況下暫停。 |
| 2.3 | 若無顯式延時：自動等待 = `15.0 − (avg_speed − 1) × 2.4` 秒。 |
| 2.4 | 休眠以 0.1 s 為增量執行，每個 tick 檢查停止/暫停標誌。 |
| 2.5 | 在迴圈模式下，各次迭代之間以 0.5 s 間隔分隔。 |
| 2.6 | 未知姿態名稱會被跳過並給出警告。 |
| 2.7 | 執行期間 Play/Pause/Stop 按鈕切換啟用/停用狀態。 |

### FR-SEQ-3：序列管理員對話方塊
透過 "🔧 Manage" 按鈕開啟的雙面板對話方塊。

| AC | 標準 |
|----|-----------|
| 3.1 | 左側面板：已儲存序列的清單方塊，帶 Execute、Edit、Delete 按鈕。 |
| 3.2 | 雙擊會執行一次序列（不迴圈），且不關閉對話方塊。 |
| 3.3 | Edit 將步驟載入建構器，並預填名稱欄位。 |

### FR-SEQ-4：序列建構器
右側面板，用於從姿態建構序列。

| AC | 標準 |
|----|-----------|
| 4.1 | 列出可用姿態；雙擊會以當前速度/延時新增一個步驟。 |
| 4.2 | 逐手指速度微調框（1–6）；"⬇ Copy from UI" 匯入主視窗的速度。 |
| 4.3 | 延時輸入會在姿態步驟後追加 `\|delay` 後綴。 |
| 4.4 | "⏱ Delay" 插入一個獨立的 `SLEEP:Xs` 步驟。 |
| 4.5 | ↑/↓ 重排，➖ 移除，🗑 清空全部。 |
| 4.6 | "💾 Save Sequence" 驗證名稱、儲存並重新整理下拉式選單。 |
| 4.7 | "▶ Execute" 在不儲存、不關閉對話方塊的情況下執行已建構的序列。 |

### FR-SEQ-5：延時輸入驗證
延時輸入中的非法浮點值會被妥善處理。

| AC | 標準 |
|----|-----------|
| 5.1 | 非數字延時會預設為無延時（新增步驟時不帶 `\|delay`）。 |
| 5.2 | 非數字 SLEEP 延時時，狀態列顯示 "Invalid delay value"。 |

## 七、舵機監控

### FR-MON-1：背景遙測擷取
一個守護執行緒以約 10 Hz 輪詢全部 8 個舵機。

| AC | 標準 |
|----|-----------|
| 1.1 | 執行緒在每次迭代之間休眠 0.1 s。 |
| 1.2 | 每個舵機擷取的指標：位置、負載、溫度、電壓、速度、運動標誌、狀態、目標。 |
| 1.3 | 讀取失敗時重複上一個已知值，以保持陣列同步。 |
| 1.4 | 回饋資料在 `feedback_lock` 下原子地更新。 |

### FR-MON-2：圖表顯示
右側面板中內嵌的 Matplotlib 圖表。

| AC | 標準 |
|----|-----------|
| 2.1 | 可選指標：Position、Target vs Current、Torque、Speed、Temperature、Voltage、Moving。 |
| 2.2 | "Servos" 下拉式選單切換 8 條曲線中哪些可見（帶 ✓ All / ✕ None）。 |
| 2.3 | 圖表重繪被限流為間隔 ≥100 ms。 |
| 2.4 | 未選擇指標 → 顯示 "Select at least one metric" 訊息。 |
| 2.5 | 無資料 → 顯示 "Waiting for data..." 訊息。 |

### FR-MON-3：圖表模式
兩種模式：Multi-Servo 與 Scope。

| AC | 標準 |
|----|-----------|
| 3.1 | Scope 模式顯示一個 "Scope Servo" 選擇器，用於聚焦單一舵機。 |
| 3.2 | Multi-Servo 隱藏 Scope Servo 選擇器。 |

### FR-MON-4：圖表縮放與平移
四個用於控制檢視的滑桿。

| AC | 標準 |
|----|-----------|
| 4.1 | Y-Zoom：0.2× 到 5.0×，預設 1.1×。 |
| 4.2 | Y-Pan：−3.0 到 +3.0，預設 0.0。 |
| 4.3 | Time-Zoom：可用資料的 10 % 到 100 %。 |
| 4.4 | Time-Pan：0 %（最早）到 100 %（最新）。 |
| 4.5 | 所有滑桿都會觸發防抖後的圖表重繪。 |

### FR-MON-5：滾動模式
將圖表限制為最新的 N 個資料點。

| AC | 標準 |
|----|-----------|
| 5.1 | 啟用且資料超過 `max_data_points`（100）時，捨棄最舊的樣本。 |
| 5.2 | 停用滾動會保留所有已擷取的資料。 |

### FR-MON-6：暫停 / 恢復 / 清空圖表

| AC | 標準 |
|----|-----------|
| 6.1 | Pause 停止圖表重繪；遙測擷取繼續。 |
| 6.2 | Clear 將所有資料陣列以及縮放/平移重設為預設值。 |

### FR-MON-7：回饋面板
顯示所有舵機即時遙測的網格表。

| AC | 標準 |
|----|-----------|
| 7.1 | 欄：S1–S8。列：Goal、Position、Speed、Torque、Voltage、Current、Temperature、Status、Moving。 |
| 7.2 | 值的格式由 `format_feedback_value()` 決定：位置 `X.XX°`、速度 `X.X°/s`、電壓 `X.XX V`、溫度 `X.X °C`、電流 `X mA`、負載 `X.X %`、狀態 `0xHH`、運動 `Yes/No`。 |
| 7.3 | 僅更新發生變化的儲存格（差分快取）。 |
| 7.4 | 重新整理被限流為更新間隔 ≥50 ms。 |

| AC | 標準 |
|----|-----------|
| 5.1 | `speeds.default` = 3，`speeds.min` = 1，`speeds.max` = 6。 |

`--list` 在不開啟連線的情況下列印所有姿態與序列。

| AC | 標準 |
|----|-----------|
| 1.1 | 輸出顯示姿態數量，每個名稱及其位置。 |

### FR-CLI-2：套用姿態
`--pose NAME` 將一個已儲存的姿態傳送到硬體。

| 2.2 | 未知姿態 → 報錯 + `sys.exit(1)`。 |

### FR-CLI-3：播放序列
`--sequence NAME` 播放序列；`--loop` 重複直到 Ctrl+C。

| AC | 標準 |
|----|-----------|
| 3.1 | 速度和延時從步驟字串解析。 |
