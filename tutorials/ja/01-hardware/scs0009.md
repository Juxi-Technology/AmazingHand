# SCS0009 配線、ID、給電

SCS0009 版は Feetech のシリアルバスサーボを 8 個使用し、PC／Raspberry Pi が USB バスドライバ基板経由で直接制御します。

## ハードウェア一覧

| 項目 | 仕様 |
|------|------|
| サーボ | Feetech SCS0009 シリアルバスサーボ ×8 |
| ドライバ基板 | USB シリアルバスドライバ基板（または Arduino + Feetech TTL Linker） |
| 給電 | 7–12V（DC5521）をドライバ基板へ入力し、ドライバ基板からサーボへ給電。ドライバ基板と共通グラウンド |
| 通信 | 1,000,000 ボーレート |

## サーボ ID と指の対応

| 指 | 右手 ID | 左手 ID |
|------|---------|---------|
| 薬指 | 5, 6 | 11, 12 |
| 中指 | 3, 4 | 13, 14 |
| 人差し指 | 1, 2 | 15, 16 |
| 親指 | 7, 8 | 17, 18 |

- **奇数 ID** が各指の 1 つ目のサーボ、**偶数 ID** が 2 つ目です。2 つ目のサーボは逆向きに取り付けられているため、換算時に符号を反転します。
- 2 つのサーボは並んで軸心が一直線にあり、**同方向の回転で開き、逆方向の回転で屈伸**を生みます。1 本の指の 2 自由度は、このサーボ対が協調して実現します。
- 左手は 9–16 ではなく **11–18** で、「薬指優先」の順に番号が振られています。
- 物理的な向き：右から左へ数え、右が奇数、左が偶数です。右手の中間位置の順序（raw 0–1023）は `451,571,451,571,451,571,451,571`、左手は `571,451,571,451,571,451,571,451` です。

## 配線

1. 8 個のサーボを ID 順にデイジーチェーン／バスドライバ基板へ接続します。
2. ドライバ基板の USB を PC または Raspberry Pi へ接続します。Linux ではユーザーを `dialout` グループに追加する必要があります。
3. 外部 7–12V 電源をドライバ基板の電源入力へ接続します（サーボの 3P 線へ直接接続しないでください）。**必ずドライバ基板と共通グラウンド**にしてください。
4. 左右手は異なる ID グループ（右手 1–8、左手 11–18）を使用し、同じバスに接続できます。制御時は「Target」で切り替えます。

## 初回通電

- 組み立て前にハンドを中間位置に合わせ、中間位置に合わせてサーボホーンを取り付けます。
- 初回接続時は [SCS0009 調整ツール](../06-servo-tuning/scs0009.md) で 1 個ずつ ID をスキャンし、中間位置と向きを確認することを推奨します。
- その後に [デスクトップ GUI/CLI](../04-desktop/scs0009.md) または [ウェブコントロール](../03-web-control/scs0009.md) で全体テストを行います。
