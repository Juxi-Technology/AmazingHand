# SCS0009 クイックスタート

SCS0009 バスサーボ版を手にしたばかりで、できるだけ早くハンドを動かしたい人向けです。詳しい説明は各章のリンクを参照してください。

## 1. 配線

- 8 個の SCS0009 サーボを ID に従ってバスドライバ基板へ接続します。右手 1–8、左手 11–18。
- USB バスドライバ基板を PC へ接続します。外部 7–12V 電源はドライバ基板の電源入力へ接続し（サーボの 3P 線へ直接接続しないでください）、ドライバ基板と共通グラウンドにします。
- 詳細な配線、ID、中間位置の順序：[SCS0009 配線、ID、給電](../01-hardware/scs0009.md)。

## 2. サーボの確認

[SCS0009 調整ツール](../06-servo-tuning/scs0009.md) または [デスクトップ GUI/CLI](../04-desktop/scs0009.md) を使用します：

1. バスをスキャンし、8 個の ID がすべて見つかることを確認します。
2. 1 個ずつ中間位置、向き、リミットを確認します。必要に応じてサーボホーンまたは中間位置を調整します。
3. すべてのサーボが 90°／中間位置へ滑らかに移動できることを確認します。

## 3. 制御方法の選択

| 方法 | 向いている用途 | 入口 |
|------|------|------|
| ウェブコントロール | スライダー、19 種のプリセットポーズ、カメラテレオペ | [SCS0009 ウェブコントロール](../03-web-control/scs0009.md) |
| デスクトップ GUI / CLI | キャリブレーション、ポーズ管理、シーケンス、テレメトリ | [SCS0009 GUI と CLI](../04-desktop/scs0009.md) |
| 公式 dora Demo | カメラ → MuJoCo IK → 実機ハンド | [SCS0009 ハンドトラッキング](../05-hand-tracking/scs0009.md) |

## 4. ウェブコントロールの最短手順

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

<http://localhost:8000> を開き、ドライバーで **SCS0009 bus** を選び、シリアルポートを選んで接続します。初回接続時は自動的に中間位置へ戻ります。

## 5. 初回動作

1. まず「すべて中間位置へ」をクリックし、ハンドが中間位置にあり、異音や引っかかりがないことを確認します。
2. 単指スライダーをドラッグし、1 本ずつ向きを確認します。
3. 次に「開く／握り拳」などのプリセットポーズを試します。
4. 問題があればまず [SCS0009 サーボ調整とキャリブレーション](../06-servo-tuning/scs0009.md) と [FAQ](../08-faq/faq.md) を確認してください。
