# SCS0009 と PWM のバージョン比較と選定

AmazingHand のハンド構造は共通ですが、2 つのサーボ構成があります。選定のポイントは、**位置フィードバック、正確な角度制御、データ収集**が必要かどうかです。

## 早見結論

- **SCS0009 を選ぶ**：位置／温度／電圧の読み戻し、正確な角度、SO-ARM101 ロボットアームへの接続による LeRobot データ収集・学習が必要な場合。
- **PWM を選ぶ**：単体デモ、ジェスチャー操作、ウェブ／デスクトップでのクイックスタートで、フィードバックが不要な場合。
- **混用しない**：2 つのハードウェアは同時に片方だけ接続してください。給電、プロトコル、ファームウェアがすべて異なります。

## 完全比較

| 比較項目 | SCS0009 シリアルバス版 | PWM サーボ版 |
|--------|--------------------|------------|
| 推奨理由 | 正確な角度制御 + データの読み戻し。SO-ARM101 ロボットアームに接続し、LeRobot のデータ収集・学習が可能 | 単体デモ、ジェスチャー操作、クイックスタート |
| サーボ型番 | Feetech SCS0009 シリアルバスサーボ ×8 | PTK 7452 MG-D **デジタル** PWM サーボ ×8 |
| サーボ仕様 | 2.3 kg·cm@6V、300° 可制御、0.293° 精度 | 4.5 kg·cm@7.4V（本構成の 5V 給電で約 2.8–3 kg·cm）、180°±10°、333 Hz リフレッシュ |
| 位置／温度／電圧／速度フィードバック | ✅ 読み戻し対応 | ❌ 読み戻しなし。ストールや脱調を検出できない |
| メインコントローラ | オンボードなし。PC／Raspberry Pi がバスドライバ基板経由で直接接続 | ESP32-S3 オンボードファームウェア |
| 集線 | サーボドライバ基板 + 9 ポートシリアルバスハブ | PWM 変換基板（3P コネクタ ×8 + 5V/GND） |
| 給電 | 7–12V（DC5521）をドライバ基板へ入力、サーボは 6V 級 | 5V / 3A 以上。変換基板と ESP32 は共通グラウンド必須 |
| ボーレート | **1,000,000** | サーボにボーレートなし。PC ↔ ESP32 のシリアル **115200 8N1** |
| サーボ ID | 設定必須：右手 1–8、左手 11–18 | ID なし。固定チャンネル CH1–CH8（人差し指 1/2、中指 3/4、薬指 5/6、親指 7/8）、左右の配線は同じ |
| 通信経路 | PC → ドライバ基板 → バス → サーボ 8 個 | PC → USB シリアル 115200 → ESP32 → PWM 8 系統 |
| コマンド形式 | Feetech バスプロトコルで角度を直接送信 | バイナリフレーム：`0x01–0x0A / 0x0C` ジェスチャー、`0xF0` 直接駆動、`0xF1` 左右手、`0x00` NOP、`0xFE` 繰り返し、`0xFF` 停止 |
| ファームウェア | なし（書き込み不要） | ESP-IDF でのビルド、またはビルド済み `amazinghand_pwm.bin` の書き込みが必要 |
| 左右手 | サーボ ID が異なる（右 1–8、左 11–18） | 同じチャンネル群を使用。コードのマッピング + `0xF1` で選択 |
| トルク解放 | トルクのオン／解放に対応 | 非対応。緊急停止はジェスチャーを中止するだけで、サーボは通電したまま位置を保持 |
| 速度制御 | 速度パラメータに対応 | 直接駆動フレームに速度パラメータはない |

## SCS0009 版の要点

- 各サーボに固有の ID があります。右手 1–8、左手 11–18。配線やサーボ交換の後は必ず ID を設定し直してください。
- シリアルバスを採用し、位置、速度、電圧、温度の読み戻しに対応します。クローズドループ制御とデータ収集に適しています。
- PC／Raspberry Pi が USB バスドライバ基板経由で直接制御するため、追加の MCU ファームウェアは不要です。
- 7–12V をドライバ基板へ入力します（サーボは 6V 級）。ドライバ基板との共通グラウンドに注意してください。
- 関節フィードバックを必要とする SO-ARM101、LeRobot などの学習フローへの接続に適しています。

## PWM 版の要点

- **PTK 7452 MG-D デジタルサーボ**（333 Hz、500–2500 µs）を使用します。SG90 などの 50 Hz アナログサーボで直接置き換えることはできません。
- サーボは 4.5 kg·cm@7.4V 定格です。本構成は 5V/3A 給電のため、実際のトルクは約 2.8–3 kg·cm になります。
- ESP32-S3 が PWM 8 系統を生成し、PC は USB シリアル 115200 でコマンドを送るだけです。
- 位置フィードバックはありません。角度、温度、電圧の読み出しも、ストール／脱調の検出もできません。
- 左右手は同じチャンネル群を共用します。各指のサーボ対は右が奇数、左が偶数で、人差し指は常に CH1/2 です。
- ファームウェアの書き込みが必要です。リポジトリにビルド済み bin があり、ESP-IDF でビルドすることもできます。
- 単体デモ、ジェスチャー操作、ウェブ／デスクトップでのクイックスタートに適しています。フィードバックに依存する LeRobot 学習には向きません。
