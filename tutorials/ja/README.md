# AmazingHand 多指ハンドチュートリアル

AmazingHand はオープンソースで 3D プリント可能なヒューマノイド型多指ハンドです。指 4 本、自由度 8、すべてのアクチュエータを手の内部に収め、手全体で約 400 g です。現在 2 種類のハードウェア構成を提供しており、機械構造は共通ですが、サーボ、ドライバ基板、通信方式が異なります。

## まず版を選ぶ

| 比較項目 | SCS0009 シリアルバス版 | PWM サーボ版 |
|--------|--------------------|------------|
| 推奨用途 | 正確な角度制御、データの読み戻し、SO-ARM101 / LeRobot のデータ収集・学習への接続 | 単体デモ、ジェスチャー操作、ウェブ／デスクトップでのクイックスタート |
| サーボ | Feetech SCS0009 シリアルバスサーボ ×8 | PTK 7452 MG-D **デジタル** PWM サーボ ×8 |
| サーボ仕様 | 2.3 kg·cm@6V、300° 可制御、0.293° 精度 | 4.5 kg·cm@7.4V（5V 給電で約 2.8–3 kg·cm）、180°±10°、333 Hz |
| 位置／温度／電圧フィードバック | ✅ 対応 | ❌ 読み戻しなし。ストールや脱調を検出できない |
| メインコントローラ | オンボードなし。PC／Raspberry Pi がバスドライバ基板経由で直接接続 | ESP32-S3 オンボードファームウェア |
| 給電 | 7–12V（DC5521）をドライバ基板へ入力 | 5V / 3A 以上、共通グラウンド必須 |
| 通信 | 1,000,000 ボーレートのバスプロトコル | PC ↔ ESP32 のシリアル **115200**（サーボ自体にボーレートはない） |
| サーボ ID | 設定必須：右手 1–8、左手 11–18 | ID なし。固定チャンネル CH1–CH8：人差し指 1/2、中指 3/4、薬指 5/6、親指 7/8 |
| ファームウェア | 書き込み不要 | ESP-IDF でのビルド、またはビルド済み bin の書き込みが必要 |

> **位置の読み戻し、精度、LeRobot の学習データ収集**が必要なら SCS0009、**単体デモ、ジェスチャー操作、クイックスタート**だけなら PWM を選んでください。

完全な比較と選定の説明は [バージョン比較](00-product/version-comparison.md) を参照してください。

## 安全上の注意

- 外部サーボ電源と ESP32／ドライバ基板は**共通グラウンド**にしてください。
- 初回通電の前にハンドを中間位置に合わせ、サーボホーンも中間位置に合わせて取り付けてください。ストローク端に当たらないようにします。
- SCS0009 と PWM の 2 つのハードウェアは**同時に片方だけ**接続してください。混在させないでください。
- PWM サーボには位置フィードバックがないため、緊急停止はジェスチャーを中止するだけです。バスサーボのようにトルクを読み出したり解放したりはできません。
