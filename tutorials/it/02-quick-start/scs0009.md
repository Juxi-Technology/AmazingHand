# Avvio rapido SCS0009

Adatto a chi ha già ricevuto la versione con servo bus SCS0009 e vuole far muovere la mano il prima possibile. Per le istruzioni complete vedi i link ai vari capitoli.

## 1. Cablaggio

- Collegare gli 8 servo SCS0009 alla scheda driver bus secondo l'ID; mano destra 1–8, mano sinistra 11–18.
- Collegare la scheda driver bus USB al PC; collegare l'alimentazione esterna 7–12 V all'ingresso della scheda driver (non direttamente al cavo 3P dei servo) e con massa comune alla scheda driver.
- Cablaggio dettagliato, ID e ordine della posizione centrale: [Cablaggio, ID e alimentazione SCS0009](../01-hardware/scs0009.md).

## 2. Verifica dei servo

Usa lo [strumento di debug SCS0009](../06-servo-tuning/scs0009.md) o la [GUI/CLI desktop](../04-desktop/scs0009.md):

1. Scansionare il bus e verificare che tutti gli 8 ID siano rilevati.
2. Verificare uno per uno posizione centrale, direzione e finecorsa; se necessario regolare il braccio o la posizione centrale.
3. Verificare che tutti i servo si muovano senza scatti fino a 90° / posizione centrale.

## 3. Scegliere la modalità di controllo

| Modalità | Adatta a | Accesso |
|------|------|------|
| Controllo web | Slider, 19 pose predefinite, teleoperazione con telecamera | [Controllo web SCS0009](../03-web-control/scs0009.md) |
| GUI desktop / CLI | Calibrazione, gestione delle pose, sequenze, telemetria | [GUI e CLI SCS0009](../04-desktop/scs0009.md) |
| Demo dora ufficiale | Telecamera → MuJoCo IK → mano reale | [Tracciamento delle mani SCS0009](../05-hand-tracking/scs0009.md) |

## 4. Percorso più breve per il controllo web

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

Apri <http://localhost:8000>, seleziona il driver **SCS0009 bus**, scegli la porta seriale e connetti; alla prima connessione la mano torna automaticamente in posizione centrale.

## 5. Primo movimento

1. Fare prima clic su «riporta tutto in posizione centrale» e verificare che la mano sia centrata e senza rumori anomali/inceppamenti.
2. Trascinare lo slider di un singolo dito e verificare le direzioni una per una.
3. Provare poi pose predefinite come «apri / pugno».
4. In caso di problemi consultare prima [Messa a punto e calibrazione SCS0009](../06-servo-tuning/scs0009.md) e le [FAQ](../08-faq/faq.md).
