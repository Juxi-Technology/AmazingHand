# Inicio rápido con SCS0009

Para usuarios que ya tienen la versión con servos de bus SCS0009 y quieren poner la mano en marcha cuanto antes. Consulta los enlaces de cada capítulo para la explicación completa.

## 1. Cableado

- Conecta los 8 servos SCS0009 a la placa controladora de bus según su ID; mano derecha 1–8, mano izquierda 11–18.
- Conecta la placa controladora de bus USB al PC; conecta la fuente externa de 7–12 V a la entrada de alimentación de la placa (no directamente al cable 3P de los servos) y comparte masa común con la placa.
- Cableado detallado, ID y orden de la posición central: [Cableado, ID y alimentación SCS0009](../01-hardware/scs0009.md).

## 2. Comprobar los servos

Usa la [herramienta de depuración SCS0009](../06-servo-tuning/scs0009.md) o la [GUI/CLI de escritorio](../04-desktop/scs0009.md):

1. Escanea el bus y confirma que se encuentran los 8 IDs.
2. Comprueba uno a uno la posición central, la dirección y los límites; ajusta las bocinas del servo o la posición central si es necesario.
3. Confirma que todos los servos se mueven suavemente hasta 90° / la posición central.

## 3. Elegir el método de control

| Método | Recomendado para | Acceso |
|------|------|------|
| Control web | Deslizadores, 19 poses predefinidas, teleoperación por cámara | [Control web SCS0009](../03-web-control/scs0009.md) |
| GUI / CLI de escritorio | Calibración, gestión de poses, secuencias, telemetría | [GUI y CLI SCS0009](../04-desktop/scs0009.md) |
| Demo oficial dora | Cámara → MuJoCo IK → mano real | [Seguimiento de manos SCS0009](../05-hand-tracking/scs0009.md) |

## 4. Ruta más corta para el control web

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

Abre <http://localhost:8000>, elige **Bus SCS0009** como controlador, selecciona el puerto serie y conéctate; en la primera conexión la mano vuelve automáticamente al centro.

## 5. Primeros movimientos

1. Pulsa primero «Todo al centro» y confirma que la mano está centrada y no hace ruidos extraños ni se agarrota.
2. Arrastra el deslizador de un solo dedo y comprueba la dirección uno a uno.
3. Prueba después poses predefinidas como «Abrir / Puño».
4. Si hay problemas, consulta primero [Depuración y calibración SCS0009](../06-servo-tuning/scs0009.md) y las [FAQ](../08-faq/faq.md).
