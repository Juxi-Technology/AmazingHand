# Depuración y calibración de servos SCS0009

La versión SCS0009 tiene dos contenidos de depuración:

1. **Montaje TTL y depuración de la posición central**: cableado, configuración del ID de servo, fijación de la bocina del servo, ajuste fino de la posición central y ejecución de pruebas.
2. **Herramienta de depuración SCS0009**: GUI en Python + PySide6 para escanear el bus, leer/escribir todos los registros, control de posición, velocidad en baudios/restauración de fábrica y copia de seguridad xdat EEPROM.

> Los detalles de los registros del protocolo están en [Tabla de memoria del protocolo SCS0009](../../../AmazingHandControl/docs/zh-hans/scs_servo_protocol.md).
> El cableado Arduino/extensiones está en [Arduino Nano](../07-arduino/arduino-nano.md).

## 1. Depuración TTL: montaje, ID y posición central

Primero, descarga el paquete de depuración de la mano diestra «灵巧手调试.zip» ([enlace](https://juxitech.feishu.cn/wiki/QjYBwL0A0iJVlNkEpUUclLYGnBc)); tras descomprimirlo, puedes seguir el documento «使用arduio程序调试灵巧手过程（TTL舵机）» (proceso de depuración de la mano diestra con el programa Arduino para servos TTL) para configurar el ID de servo, calibrar, ajustar la posición central y ejecutar el programa de demostración, o consultar el [código oficial de código abierto](https://github.com/pollen-robotics/AmazingHand/tree/main/ArduinoExample).

**Con el producto sin desmontar** (el ID de servo, la calibración y la posición central ya vienen ajustados de fábrica), puedes pasar directamente al [punto 6, ejecutar el «programa de demostración 02»](#6-ejecutar-el-programa-de-demostración-02) y al [seguimiento de manos](../05-hand-tracking/scs0009.md).

## 2. Herramienta de depuración SCS0009

Aplicable a Windows 10 / 11; las diferencias con Linux y macOS están en la [sección 8](#8-diferencias-entre-linux-y-macos). Este tutorial cubre todos los pasos, desde la instalación del entorno hasta la depuración completa.

> ⚠️ **Nota de compatibilidad: esta herramienta actualmente solo admite servos Feetech SCS0009** (serie SCS, realimentación de posición por potenciómetro, resolución de 10 bits 0–1023). La tabla de registros y el formato de parámetros xdat están diseñados para el Feetech SCS0009; no se garantiza la compatibilidad con otras marcas/modelos.

### 1. Requisitos del entorno

| Dependencia | Versión | Descripción |
|------|------|------|
| Python | >= 3.8 | Se recomienda 3.10+, descárgalo de [python.org](https://www.python.org/downloads/) |
| PySide6 | >= 6.0 | Framework de la GUI |
| pyserial | >= 3.5 | Comunicación por puerto serie |
| Sistema | Win10 / Win11 | Cualquier versión |

### 2. Instalar Python

1. Visita <https://www.python.org/downloads/>
2. Descarga el instalador de Python 3.10+
3. Durante la instalación, **asegúrate de marcar "Add Python to PATH"** (de lo contrario, la línea de comandos no encontrará python)

Verificar la instalación:

```bash
python --version
```

### 3. Instalar dependencias

Se recomienda instalarlas en un entorno virtual para no contaminar el Python del sistema:

```bash
# entrar en el directorio del proyecto
cd SCS0009_ServoController

# crear el entorno virtual
python -m venv .venv

# activar el entorno virtual (Windows)
.venv\Scripts\activate

# instalar dependencias
pip install -r requirements.txt
```

> ⚠️ **El entorno virtual solo hay que crearlo una vez**. Ejecutarlo repetidamente sobrescribe el entorno original (borra las dependencias instaladas). Después basta con `activate` cada vez.

> Consejo: tras activar, aparecerá el prefijo `(.venv)` en la línea de comandos.

### 4. Comprobar el entorno

```bash
python setup.py
```

Si ves `[OK] 环境检查通过，可以运行项目`, el entorno es correcto.

### 5. Conectar el hardware

1. Conecta el adaptador USB-serie (como CH340 / CP2102) al PC
2. Conecta el controlador de servos (placa controladora del brazo robótico)
3. Alimenta los servos (se recomienda DC 5V 5A; versión Pro DC 12V 5A)

Abre el Administrador de dispositivos (`Win+X` → Administrador de dispositivos) y confirma el número de puerto:

```
端口 (COM 和 LPT)
  └─ USB-SERIAL CH340 (COM3)     ← 你的舵机串口
```

> **Anota el número COM**; lo necesitarás al iniciar el programa.

### 6. Iniciar la GUI

```bash
python -m src.gui.factory_calibration_tool
```

O especifica el puerto manualmente (si el puerto serie está ocupado):

```bash
python -m src.gui.factory_calibration_tool --port COM3
```

Ver los puertos disponibles:

```bash
python -m src.gui.factory_calibration_tool --list-ports
```

### 7. Flujo de operación de la interfaz

> La interfaz tiene un diseño de panel único; cuando la altura de la ventana es insuficiente aparece una barra de desplazamiento automáticamente y, al maximizar, se adapta estirándose.

#### 7.1 Conexión del puerto serie

- Selecciona el puerto y la velocidad en baudios (1M por defecto) y pulsa **Conectar**
- El estado muestra `🟢 已连接`

#### 7.2 Escanear servos

- Pulsa **Escanear servos** para detectar los servos en línea con ID 1-254
- Los resultados del escaneo se muestran en tiempo real en la lista de servos (con modelo)
- Al pulsar una fila de la lista de servos → se rellena automáticamente en el desplegable de servo

#### 7.3 Lectura/escritura de parámetros

- **Leer parámetros**: lee los 44 registros (EEPROM + SRAM); el registro muestra los resultados en tiempo real
- **Tabla de parámetros**: 5 columnas (dirección/registro/valor/zona de almacenamiento/lectura-escritura); EPROM/SRAM/DEFAULT se distinguen por color
- **Selección vinculada**: al pulsar una fila de la tabla de parámetros → se rellenan automáticamente «dirección de escritura», «longitud» y «valor»
- **Escritura**: tras modificar el valor, pulsa escribir; el programa desbloquea/escribe/bloquea automáticamente
- **Ventana de resultado de escritura**: si tiene éxito muestra un aviso verde «✅ 已成功写入»; si falla, un aviso rojo «❌ 写入失败» (con el motivo)

#### 7.4 Modificar el ID de servo

1. **Conecta al bus solo este servo, el que se va a cambiar de ID**, para evitar conflictos con IDs existentes.
2. En la tabla de parámetros, localiza la fila «ID de servo» (dirección `0x05`) y selecciónala.
3. Cambia el «valor» por el ID objetivo y pulsa **✏️ Escribir**; el programa desbloqueará → escribirá → volverá a bloquear automáticamente.
4. Tras cambiarlo, vuelve a escanear el bus para confirmar. Mano derecha 1–8, mano izquierda 11–18.

#### 7.5 Control de posición

1. Arrastra el deslizador o introduce directamente la posición objetivo (0–1023); la caja numérica y el deslizador están sincronizados.
2. Pulsa **▶ Mover**; la barra de estado muestra «Moviendo…».
3. Al llegar, avisa «Movimiento completado, desactiva el par»; pulsa **⏹ Par off**.

#### 7.6 Velocidad en baudios/restauración de fábrica

- **Modificar la velocidad en baudios**: elige la nueva velocidad (38400–1000000 bps) y escríbela; el programa cambia la velocidad del puerto serie y verifica con ping, y revierte automáticamente si falla.
- **Restaurar de fábrica**: restaura los valores de fábrica (ID=1, velocidad 1M); después hay que volver a escanear.

#### 7.7 Parámetros xdat (solo guarda EEPROM)

1. `💾 保存当前舵机`: guarda los parámetros EEPROM del servo con el ID actual en un archivo xdat (copia de seguridad)
2. `📂 打开 xdat`: carga el archivo de copia de seguridad
3. `📤 恢复参数到舵机`: escribe la copia de seguridad de vuelta en el servo

### 8. Diferencias entre Linux y macOS

#### Linux

- **Fuentes**: `sudo apt install fonts-noto-cjk fonts-noto-color-emoji`; de lo contrario la interfaz en chino puede aparecer en blanco y los emoji como cuadrados.
- **Permisos del puerto serie**: `sudo usermod -a -G dialout $USER`, cierra sesión y vuelve a entrar para que surta efecto; `groups` debe incluir `dialout`. Temporalmente puedes usar `sudo chmod 666 /dev/ttyUSB0`.
- **Nombre del dispositivo**: `/dev/ttyUSB*` (CH340 / CP2102 / PL2303) o `/dev/ttyACM*` (puerto serie USB integrado); usa `lsusb`, `dmesg | grep -i tty` para averiguar el fabricante.
- **Nombre de dispositivo fijo (opcional)**: escribe en `/etc/udev/rules.d/99-servo.rules` `SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="7523", SYMLINK+="ttyServo"` y después usa `/dev/ttyServo`.
- **Inicio**: `python -m src.gui.factory_calibration_tool --port /dev/ttyUSB0`.
- **Preguntas frecuentes**: si `pip` da externally-managed-environment, usa venv o añade `--break-system-packages`.

#### macOS

- **Python**: se recomienda instalarlo con Homebrew (`brew install python`); no uses la versión antigua del sistema.
- **Nombres de puerto serie**: usa `/dev/cu.*`, no `/dev/tty.*` (este último puede bloquearse); consulta con `ls /dev/cu.*`.
- **Controlador USB**: CH340 / CP2102 / FTDI suelen ser plug-and-play; los CH340 de lotes antiguos necesitan el controlador WCH; puedes diagnosticar con `system_profiler SPUSBDataType`.
- **Inicio**: `python -m src.gui.factory_calibration_tool --port /dev/cu.usbserial-0001`.
- **Apple Silicon**: usa Python 3.10+ nativo, evita el Python antiguo bajo Rosetta; si en la primera ejecución aparece «no se puede verificar al desarrollador», permítelo en «Privacidad y seguridad».
- **Ahorro de energía**: la suspensión de macOS puede desconectar el puerto serie; mantén el equipo despierto durante la operación.

### 9. Notas

1. **La escritura es persistente**: tras escribir en la EEPROM, el valor original se sobrescribe y no se puede deshacer; haz antes una copia xdat.
2. **Alimentación estable**: una alimentación insuficiente provoca pérdida de pasos, fallos de comunicación o desconexión de los servos; alimenta según los requisitos de [Cableado y alimentación SCS0009](../01-hardware/scs0009.md).
3. **Puerto serie exclusivo**: un mismo puerto no puede abrirse desde dos programas a la vez; cierra antes el monitor serie, la aplicación de escritorio u otros programas que lo ocupen.
4. **Riesgo al cambiar el ID**: conecta al bus solo un servo, el que se va a cambiar de ID; si tras el cambio se pierde la conexión, prueba «Restaurar de fábrica» (el ID vuelve a 1).
5. **Sobrecalentamiento/sobretensión**: la herramienta monitoriza voltaje y temperatura (aviso si la temperatura > 60 °C); si la temperatura alta persiste, detén y deja enfriar.
6. **Conexión en caliente**: al desconectar el USB el programa intenta reconectarse; tras volver a conectarlo, pulsa actualizar puertos.
7. **Caracteres ilegibles en la consola de Windows**: si la herramienta de línea de comandos muestra emojis ilegibles, configura `PYTHONIOENCODING=utf-8` y vuelve a ejecutar.

### 10. Preguntas frecuentes

| Problema | Solución |
|------|------|
| No se encuentra el puerto serie | Comprueba el controlador en el Administrador de dispositivos; cambia el puerto USB; instala el controlador CH340 |
| El puerto serie está ocupado | Cierra el monitor serie y otros programas; reinicia la herramienta |
| La fuente china se muestra en blanco | La fuente predeterminada del sistema es Microsoft YaHei; si hay problemas, instala una fuente china |
| No se detectan servos | Comprueba alimentación/cableado; confirma la velocidad 1M |
| Fallo de escritura | Comprueba la alimentación y conexión del servo; confirma que el registro objetivo se pueda escribir |
| PermissionError al abrir el puerto serie | Asegúrate de que ningún otro proceso ocupe ese puerto COM |
| Linux: `Permission denied: /dev/ttyUSB0` | No se ha añadido al grupo `dialout`; ver la sección de Linux arriba |
| macOS: se bloquea con un puerto serie con nombre `tty.` | Usa el dispositivo `/dev/cu.*` correspondiente |
