# SCS0009 Quick Start

For users who already have the SCS0009 bus servo version and want to get the hand moving as quickly as possible. See the chapter links for full details.

## 1. Wiring

- Connect the 8 SCS0009 servos to the bus driver board by ID; right hand 1–8, left hand 11–18.
- Connect the USB bus driver board to the computer; connect the external 7–12V power supply to the driver board's power input (do not connect it directly to the servos' 3P wires), with a common ground to the driver board.
- Detailed wiring, IDs and middle-position order: [SCS0009 wiring, ID and power](../01-hardware/scs0009.md).

## 2. Check the servos

Use the [SCS0009 debug tool](../06-servo-tuning/scs0009.md) or the [desktop GUI/CLI](../04-desktop/scs0009.md):

1. Scan the bus and confirm that all 8 IDs are found.
2. Check the middle position, direction and limits one by one; adjust the servo horns or middle position if necessary.
3. Confirm that every servo can move smoothly to 90° / the middle position.

## 3. Choose a control method

| Method | Best for | Entry point |
|------|------|------|
| Web control | Sliders, 19 preset poses, camera teleoperation | [SCS0009 web control](../03-web-control/scs0009.md) |
| Desktop GUI / CLI | Calibration, pose management, sequences, telemetry | [SCS0009 GUI and CLI](../04-desktop/scs0009.md) |
| Official dora demo | Camera → MuJoCo IK → real hand | [SCS0009 hand tracking](../05-hand-tracking/scs0009.md) |

## 4. Shortest web-control path

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

Open <http://localhost:8000>, select driver **SCS0009 bus**, choose the serial port and connect; the first connection automatically returns to the middle position.

## 5. First motion

1. First click "All to middle" and confirm the hand is at the middle position with no abnormal noise or binding.
2. Drag the single-finger sliders and check the direction one finger at a time.
3. Then try preset poses such as "open / fist".
4. If there are problems, first see [SCS0009 debugging and calibration](../06-servo-tuning/scs0009.md) and the [FAQ](../08-faq/faq.md).
