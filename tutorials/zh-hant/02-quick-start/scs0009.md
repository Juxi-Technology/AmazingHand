# SCS0009 快速上手

適合已經拿到 SCS0009 匯流排伺服馬達版本、想盡快讓手動起來的使用者。完整說明見各章節連結。

## 1. 接線

- 8 個 SCS0009 伺服馬達按 ID 接入匯流排驅動板；右手 1–8，左手 11–18。
- USB 匯流排驅動板接電腦；外部 7–12V 電源接驅動板電源輸入（不要直接接伺服馬達 3P 線），並與驅動板共地。
- 詳細接線、ID 與中位順序：[SCS0009 接線、ID 與供電](../01-hardware/scs0009.md)。

## 2. 檢查伺服馬達

使用 [SCS0009 調校工具](../06-servo-tuning/scs0009.md) 或 [桌面 GUI/CLI](../04-desktop/scs0009.md)：

1. 掃描匯流排，確認 8 個 ID 都能找到。
2. 逐個檢查中位、方向和限位；必要時調整伺服馬達臂或中位。
3. 確認所有伺服馬達都能平滑移動到 90° / 中位。

## 3. 選擇控制方式

| 方式 | 適合 | 入口 |
|------|------|------|
| 網頁控制 | 滑桿、19 個預設姿態、攝影機遙操作 | [SCS0009 網頁控制](../03-web-control/scs0009.md) |
| 桌面 GUI / CLI | 標定、姿態管理、序列、遙測 | [SCS0009 GUI 與 CLI](../04-desktop/scs0009.md) |
| 官方 dora Demo | 攝影機 → MuJoCo IK → 真實手 | [SCS0009 手勢追蹤](../05-hand-tracking/scs0009.md) |

## 4. 網頁控制最短路徑

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

開啟 <http://localhost:8000>，驅動選 **SCS0009 匯流排**，選序列埠並連線；第一次連線會自動回中位。

## 5. 首次動作

1. 先點「全部回中位」，確認手在中位且沒有異音/卡澀。
2. 拖動單指滑桿，逐個確認方向。
3. 再試「張開 / 握拳」等預設姿態。
4. 有問題先看 [SCS0009 調校與標定](../06-servo-tuning/scs0009.md) 和 [FAQ](../08-faq/faq.md)。
