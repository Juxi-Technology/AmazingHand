# SCS0009 與 PWM 版本比較與選型

AmazingHand 的機械手結構相同，但有兩套伺服馬達方案。選型主要看是否需要**位置回饋、精確角度控制和資料採集**。

## 快速結論

- **選 SCS0009**：需要位置/溫度/電壓回讀、精確角度、接入 SO-ARM101 機械臂做 LeRobot 資料採集訓練。
- **選 PWM**：獨立演示、手勢互動、網頁/桌面快速上手，不需要回饋。
- **不要混用**：兩套硬體同一時刻只接一套，供電、協定和韌體都不同。

## 完整對比

| 對比項目 | SCS0009 序列匯流排版 | PWM 伺服馬達版 |
|--------|--------------------|------------|
| 推薦理由 | 精確角度控制 + 資料回讀；可接入 SO-ARM101 機械臂，做 LeRobot 資料採集訓練 | 獨立演示、手勢互動、快速上手 |
| 伺服馬達型號 | 飛特 SCS0009 序列匯流排伺服馬達 ×8 | PTK 7452 MG-D **數位** PWM 伺服馬達 ×8 |
| 伺服馬達參數 | 2.3 kg·cm@6V，300° 可控，0.293° 精度 | 4.5 kg·cm@7.4V（本方案 5V 供電約 2.8–3 kg·cm），180°±10°，333 Hz 刷新 |
| 位置/溫度/電壓/速度回饋 | ✅ 支援回讀 | ❌ 無回讀，無法偵測堵轉或失步 |
| 主控 | 無板載；電腦/樹莓派透過匯流排驅動板直連 | ESP32-S3 板載韌體 |
| 集線 | 伺服馬達驅動板 + 9 路序列匯流排集線器 | PWM 轉接板（8 個 3P 針座 + 5V/GND） |
| 供電 | 7–12V（DC5521）輸入驅動板，伺服馬達標稱 6V 級 | 5V / 3A 以上，轉接板與 ESP32 必須共地 |
| 鮑率 | **1,000,000** | 伺服馬達無鮑率；上位機↔ESP32 序列埠 **115200 8N1** |
| 伺服馬達 ID | 必須設定：右手 1–8，左手 11–18 | 不設 ID；固定通道 CH1–CH8（食指 1/2、中指 3/4、無名指 5/6、拇指 7/8），左右手接線相同 |
| 通訊鏈路 | 上位機 → 驅動板 → 匯流排 → 8 個伺服馬達 | 上位機 → USB 序列埠 115200 → ESP32 → 8 路 PWM |
| 指令形式 | 飛特匯流排協定，直接下發角度 | 二進位幀：`0x01–0x0A / 0x0C` 手勢、`0xF0` 直驅、`0xF1` 左右手、`0x00` NOP、`0xFE` 重複、`0xFF` 停止 |
| 韌體 | 無（不需要燒錄） | 需要 ESP-IDF 編譯，或直接燒錄預編譯 `amazinghand_pwm.bin` |
| 左右手 | 不同伺服馬達 ID（右 1–8、左 11–18） | 同一組通道，程式映射 + `0xF1` 選邊 |
| 力矩釋放 | 支援扭矩開關/釋放 | 不支援；急停只中止手勢，伺服馬達仍通電保持位置 |
| 速度控制 | 支援速度參數 | 直驅幀無速度參數 |

## SCS0009 版本要點

- 每個伺服馬達都有唯一 ID；右手 1–8、左手 11–18，接線/換伺服馬達後必須重新設定 ID。
- 採用序列匯流排，支援位置、速度、電壓、溫度回讀，適合閉迴路控制和資料採集。
- 電腦/樹莓派透過 USB 匯流排驅動板直接控制，不需要額外 MCU 韌體。
- 供電 7–12V 輸入匯流排驅動板（伺服馬達為 6V 級），注意與驅動板共地。
- 適合接入 SO-ARM101、LeRobot 等需要關節回饋的訓練流程。

## PWM 版本要點

- 使用 **PTK 7452 MG-D 數位伺服馬達**（333 Hz、500–2500 µs），不能用 SG90 等 50 Hz 類比伺服馬達直接替換。
- 伺服馬達標稱 4.5 kg·cm@7.4V；本方案按 5V/3A 供電，實際扭矩約 2.8–3 kg·cm。
- ESP32-S3 產生 8 路 PWM，上位機只需透過 USB 序列埠 115200 發送命令。
- 沒有位置回饋；無法讀取角度、溫度、電壓，也無法偵測堵轉/失步。
- 左右手共用同一組通道；每指一對伺服馬達右邊奇數、左邊偶數，食指固定 CH1/2。
- 需要燒錄韌體；儲存庫提供預編譯 bin，也可用 ESP-IDF 編譯。
- 適合獨立演示、手勢互動、網頁/桌面快速上手；不適合依賴回饋的 LeRobot 訓練。
