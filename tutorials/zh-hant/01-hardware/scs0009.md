# SCS0009 接線、ID 與供電

SCS0009 版本使用 8 個飛特序列匯流排伺服馬達，電腦/樹莓派透過 USB 匯流排驅動板直接控制。

## 硬體清單

| 項目 | 規格 |
|------|------|
| 伺服馬達 | 飛特 SCS0009 序列匯流排伺服馬達 ×8 |
| 驅動板 | USB 序列匯流排驅動板（或 Arduino + Feetech TTL Linker） |
| 供電 | 7–12V（DC5521）輸入驅動板，由驅動板給伺服馬達供電；與驅動板共地 |
| 通訊 | 1,000,000 鮑率 |

## 伺服馬達 ID 與手指對應

| 手指 | 右手 ID | 左手 ID |
|------|---------|---------|
| 無名指 | 5, 6 | 11, 12 |
| 中指 | 3, 4 | 13, 14 |
| 食指 | 1, 2 | 15, 16 |
| 拇指 | 7, 8 | 17, 18 |

- **奇數 ID** 是每根手指的第一個伺服馬達，**偶數 ID** 是第二個；第二個伺服馬達反向安裝，換算時取負。
- 兩個伺服馬達並排、軸心共線：**同向旋轉產生側擺，反向旋轉產生屈伸**，所以一根手指的 2 個自由度由這一對伺服馬達共同完成。
- 左手不是 9–16，而是 **11–18**，按「無名指優先」編號。
- 物理方向：從右往左數，右邊奇數、左邊偶數。右手中位順序（raw 0–1023）`451,571,451,571,451,571,451,571`；左手 `571,451,571,451,571,451,571,451`。

## 接線

1. 8 個伺服馬達按 ID 順序串接/接入匯流排驅動板。
2. 驅動板 USB 接電腦或樹莓派；Linux 需要把使用者加入 `dialout` 群組。
3. 外部 7–12V 電源接驅動板的電源輸入（不要直接接到伺服馬達 3P 線），**必須與驅動板共地**。
4. 左右手使用不同 ID 組（右手 1–8、左手 11–18），可以接在同一條匯流排上；控制時用「控制對象」切換。

## 首次上電

- 組裝前把機械手擺到中位，按中位安裝伺服馬達臂。
- 首次連接建議用 [SCS0009 調校工具](../06-servo-tuning/scs0009.md) 逐個掃描 ID、檢查中位和方向。
- 再用 [桌面 GUI/CLI](../04-desktop/scs0009.md) 或 [網頁控制](../03-web-control/scs0009.md) 做整體測試。
