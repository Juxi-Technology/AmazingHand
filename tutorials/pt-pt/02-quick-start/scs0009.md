# Início rápido SCS0009

Para utilizadores que já têm a versão com servos de barramento SCS0009 e querem pôr a mão a mexer o mais depressa possível. Consulte os links de cada capítulo para a explicação completa.

## 1. Cablagem

- Ligue os 8 servos SCS0009 à placa controladora de barramento pela ordem dos IDs; mão direita 1–8, mão esquerda 11–18.
- Ligue a placa controladora de barramento USB ao PC; a alimentação externa de 7–12V liga-se à entrada de alimentação da placa controladora (não diretamente ao cabo 3P dos servos), com massa comum com a placa controladora.
- Cablagem detalhada, IDs e sequência da posição central: [Cablagem, ID e alimentação SCS0009](../01-hardware/scs0009.md).

## 2. Verificar os servos

Utilize a [ferramenta de depuração SCS0009](../06-servo-tuning/scs0009.md) ou a [GUI/CLI de desktop](../04-desktop/scs0009.md):

1. Procure no barramento e confirme que os 8 IDs são encontrados.
2. Verifique um a um a posição central, o sentido e os limites; ajuste o braço ou a posição central se necessário.
3. Confirme que todos os servos se deslocam suavemente até 90° / à posição central.

## 3. Escolher o modo de controlo

| Modo | Adequado a | Entrada |
|------|------|------|
| Controlo web | Sliders, 19 poses predefinidas, teleoperação por câmara | [Controlo web SCS0009](../03-web-control/scs0009.md) |
| GUI / CLI de desktop | Calibração, gestão de poses, sequências, telemetria | [GUI e CLI SCS0009](../04-desktop/scs0009.md) |
| Demo oficial dora | Câmara → IK em MuJoCo → mão real | [Seguimento de mãos SCS0009](../05-hand-tracking/scs0009.md) |

## 4. Caminho mais curto para o controlo web

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

Abra <http://localhost:8000>, escolha o driver **SCS0009 bus**, selecione a porta série e ligue; a primeira ligação regressa automaticamente ao centro.

## 5. Primeiros movimentos

1. Clique primeiro em «Todos ao centro» e confirme que a mão está na posição central, sem ruídos anómalos nem bloqueio.
2. Arraste os sliders de cada dedo e confirme o sentido de cada um.
3. Experimente depois as poses predefinidas, como «Abrir / Punho».
4. Em caso de problema, consulte primeiro a [Depuração e calibração SCS0009](../06-servo-tuning/scs0009.md) e as [FAQ](../08-faq/faq.md).
