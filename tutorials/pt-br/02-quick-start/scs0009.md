# Início rápido com SCS0009

Para quem já recebeu a versão com servos de barramento SCS0009 e quer colocar a mão em movimento o quanto antes. Consulte os links de cada capítulo para a documentação completa.

## 1. Fiação

- Conecte os 8 servos SCS0009 à placa driver de barramento conforme os IDs; mão direita 1–8, mão esquerda 11–18.
- Conecte a placa driver de barramento USB ao computador; conecte a fonte externa de 7–12 V à entrada de alimentação da placa driver (não direto nos fios 3P dos servos), com aterramento comum com a placa driver.
- Fiação detalhada, IDs e ordem do meio: [Fiação, ID e alimentação SCS0009](../01-hardware/scs0009.md).

## 2. Verificar os servos

Use a [ferramenta de depuração SCS0009](../06-servo-tuning/scs0009.md) ou a [GUI/CLI de desktop](../04-desktop/scs0009.md):

1. Escaneie o barramento e confirme que os 8 IDs são encontrados.
2. Verifique o meio, a direção e os limites de cada servo; ajuste os horns ou o meio se necessário.
3. Confirme que todos os servos se movem suavemente até 90° / a posição do meio.

## 3. Escolher a forma de controle

| Método | Indicado para | Acesso |
|------|------|------|
| Controle web | Controles deslizantes, 19 poses predefinidas, teleoperação por câmera | [Controle web SCS0009](../03-web-control/scs0009.md) |
| GUI / CLI de desktop | Calibração, gerenciamento de poses, sequências, telemetria | [GUI e CLI SCS0009](../04-desktop/scs0009.md) |
| Demo oficial dora | Câmera → MuJoCo IK → mão real | [Rastreamento de mãos SCS0009](../05-hand-tracking/scs0009.md) |

## 4. Caminho mais curto pelo controle web

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

Abra <http://localhost:8000>, selecione o driver **Barramento SCS0009**, escolha a porta serial e conecte; na primeira conexão a mão retorna automaticamente ao meio.

## 5. Primeiros movimentos

1. Primeiro clique em “centralizar tudo” e confirme que a mão está no meio, sem ruído anormal nem travamento.
2. Arraste os controles deslizantes de cada dedo e confirme a direção, um a um.
3. Depois teste poses predefinidas como “abrir / punho fechado”.
4. Se houver problemas, consulte primeiro [Depuração e calibração SCS0009](../06-servo-tuning/scs0009.md) e as [Perguntas frequentes](../08-faq/faq.md).
