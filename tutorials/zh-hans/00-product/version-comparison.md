# SCS0009 与 PWM 版本对比与选型

AmazingHand 的机械手结构相同，但有两套舵机方案。选型主要看是否需要**位置反馈、精确角度控制和数据采集**。

## 快速结论

- **选 SCS0009**：需要位置/温度/电压回读、精确角度、接入 SO-ARM101 机械臂做 LeRobot 数据采集训练。
- **选 PWM**：独立演示、手势交互、网页/桌面快速上手，不需要反馈。
- **不要混用**：两套硬件同一时刻只接一套，供电、协议和固件都不同。

## 完整对比

| 对比项 | SCS0009 串口总线版 | PWM 舵机版 |
|--------|--------------------|------------|
| 推荐理由 | 精确角度控制 + 数据回读；可接入 SO-ARM101 机械臂，做 LeRobot 数据采集训练 | 独立演示、手势交互、快速上手 |
| 舵机型号 | 飞特 SCS0009 串行总线舵机 ×8 | PTK 7452 MG-D **数字** PWM 舵机 ×8 |
| 舵机参数 | 2.3 kg·cm@6V，300° 可控，0.293° 精度 | 4.5 kg·cm@7.4V（本方案 5V 供电约 2.8–3 kg·cm），180°±10°，333 Hz 刷新 |
| 位置/温度/电压/速度反馈 | ✅ 支持回读 | ❌ 无回读，无法检测堵转或失步 |
| 主控 | 无板载；电脑/树莓派通过总线驱动板直连 | ESP32-S3 板载固件 |
| 集线 | 舵机驱动板 + 9 路串口总线集线器 | PWM 转接板（8 个 3P 针座 + 5V/GND） |
| 供电 | 7–12V（DC5521）输入驱动板，舵机标称 6V 级 | 5V / 3A 以上，转接板与 ESP32 必须共地 |
| 波特率 | **1,000,000** | 舵机无波特率；上位机↔ESP32 串口 **115200 8N1** |
| 舵机 ID | 必须设置：右手 1–8，左手 11–18 | 不设 ID；固定通道 CH1–CH8（食指 1/2、中指 3/4、无名指 5/6、拇指 7/8），左右手接线相同 |
| 通信链路 | 上位机 → 驱动板 → 总线 → 8 个舵机 | 上位机 → USB 串口 115200 → ESP32 → 8 路 PWM |
| 指令形式 | 飞特总线协议，直接下发角度 | 二进制帧：`0x01–0x0A / 0x0C` 手势、`0xF0` 直驱、`0xF1` 左右手、`0x00` NOP、`0xFE` 重复、`0xFF` 停止 |
| 固件 | 无（不需要烧录） | 需要 ESP-IDF 编译，或直接烧录预编译 `amazinghand_pwm.bin` |
| 左右手 | 不同舵机 ID（右 1–8、左 11–18） | 同一组通道，代码映射 + `0xF1` 选边 |
| 力矩释放 | 支持扭矩开关/释放 | 不支持；急停只中止手势，舵机仍通电保持位置 |
| 速度控制 | 支持速度参数 | 直驱帧无速度参数 |

## SCS0009 版本要点

- 每个舵机都有唯一 ID；右手 1–8、左手 11–18，接线/换舵机后必须重新设置 ID。
- 采用串行总线，支持位置、速度、电压、温度回读，适合闭环控制和数据采集。
- 电脑/树莓派通过 USB 总线驱动板直接控制，不需要额外 MCU 固件。
- 供电 7–12V 输入总线驱动板（舵机为 6V 级），注意与驱动板共地。
- 适合接入 SO-ARM101、LeRobot 等需要关节反馈的训练流程。

## PWM 版本要点

- 使用 **PTK 7452 MG-D 数字舵机**（333 Hz、500–2500 µs），不能用 SG90 等 50 Hz 模拟舵机直接替换。
- 舵机标称 4.5 kg·cm@7.4V；本方案按 5V/3A 供电，实际扭矩约 2.8–3 kg·cm。
- ESP32-S3 产生 8 路 PWM，上位机只需通过 USB 串口 115200 发命令。
- 没有位置反馈；无法读取角度、温度、电压，也无法检测堵转/失步。
- 左右手共用同一组通道；每指一对舵机右边奇数、左边偶数，食指固定 CH1/2。
- 需要烧录固件；仓库提供预编译 bin，也可用 ESP-IDF 编译。
- 适合独立演示、手势交互、网页/桌面快速上手；不适合依赖反馈的 LeRobot 训练。
