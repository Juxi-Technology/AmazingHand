# SCS0009 快速上手

适合已经拿到 SCS0009 总线舵机版本、想尽快让手动起来的用户。完整说明见各章节链接。

## 1. 接线

- 8 个 SCS0009 舵机按 ID 接入总线驱动板；右手 1–8，左手 11–18。
- USB 总线驱动板接电脑；外部 7–12V 电源接驱动板电源输入（不要直接接舵机 3P 线），并与驱动板共地。
- 详细接线、ID 与中位顺序：[SCS0009 接线、ID 与供电](../01-hardware/scs0009.md)。

## 2. 检查舵机

使用 [SCS0009 调试工具](../06-servo-tuning/scs0009.md) 或 [桌面 GUI/CLI](../04-desktop/scs0009.md)：

1. 扫描总线，确认 8 个 ID 都能找到。
2. 逐个检查中位、方向和限位；必要时调整舵机臂或中位。
3. 确认所有舵机都能平滑移动到 90° / 中位。

## 3. 选择控制方式

| 方式 | 适合 | 入口 |
|------|------|------|
| 网页控制 | 滑块、19 个预设姿态、摄像头遥操作 | [SCS0009 网页控制](../03-web-control/scs0009.md) |
| 桌面 GUI / CLI | 标定、姿态管理、序列、遥测 | [SCS0009 GUI 与 CLI](../04-desktop/scs0009.md) |
| 官方 dora Demo | 摄像头 → MuJoCo IK → 真实手 | [SCS0009 手势追踪](../05-hand-tracking/scs0009.md) |

## 4. 网页控制最短路径

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

打开 <http://localhost:8000>，驱动选 **SCS0009 总线**，选串口并连接；第一次连接会自动回中位。

## 5. 首次动作

1. 先点“全部回中位”，确认手在中位且没有异响/卡涩。
2. 拖动单指滑块，逐个确认方向。
3. 再试“张开 / 握拳”等预设姿态。
4. 有问题先看 [SCS0009 调试与标定](../06-servo-tuning/scs0009.md) 和 [FAQ](../08-faq/faq.md)。
