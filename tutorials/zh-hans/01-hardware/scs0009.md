# SCS0009 接线、ID 与供电

SCS0009 版本使用 8 个飞特串行总线舵机，电脑/树莓派通过 USB 总线驱动板直接控制。

## 硬件清单

| 项目 | 规格 |
|------|------|
| 舵机 | 飞特 SCS0009 串行总线舵机 ×8 |
| 驱动板 | USB 串口总线驱动板（或 Arduino + Feetech TTL Linker） |
| 供电 | 7–12V（DC5521）输入驱动板，由驱动板给舵机供电；与驱动板共地 |
| 通信 | 1,000,000 波特率 |

## 舵机 ID 与手指对应

| 手指 | 右手 ID | 左手 ID |
|------|---------|---------|
| 无名指 | 5, 6 | 11, 12 |
| 中指 | 3, 4 | 13, 14 |
| 食指 | 1, 2 | 15, 16 |
| 拇指 | 7, 8 | 17, 18 |

- **奇数 ID** 是每根手指的第一个舵机，**偶数 ID** 是第二个；第二个舵机反向安装，换算时取负。
- 两个舵机并排、轴心共线：**同向旋转产生侧摆，反向旋转产生屈伸**，所以一根手指的 2 个自由度由这一对舵机共同完成。
- 左手不是 9–16，而是 **11–18**，按“无名指优先”编号。
- 物理方向：从右往左数，右边奇数、左边偶数。右手中位顺序（raw 0–1023）`451,571,451,571,451,571,451,571`；左手 `571,451,571,451,571,451,571,451`。

## 接线

1. 8 个舵机按 ID 顺序串接/接入总线驱动板。
2. 驱动板 USB 接电脑或树莓派；Linux 需要把用户加入 `dialout` 组。
3. 外部 7–12V 电源接驱动板的电源输入（不要直接接到舵机 3P 线），**必须与驱动板共地**。
4. 左右手使用不同 ID 组（右手 1–8、左手 11–18），可以接在同一根总线上；控制时用「控制对象」切换。

## 首次上电

- 组装前把机械手摆到中位，按中位安装舵机臂。
- 首次连接建议用 [SCS0009 调试工具](../06-servo-tuning/scs0009.md) 逐个扫描 ID、检查中位和方向。
- 再用 [桌面 GUI/CLI](../04-desktop/scs0009.md) 或 [网页控制](../03-web-control/scs0009.md) 做整体测试。
