# SCS0009 舵机调试与标定

SCS0009 版本有两套调试内容：

1. **TTL 组装与中位调试**：接线、设置舵机 ID、固定舵机臂、微调中位、运行测试。
2. **SCS0009 调试工具**：Python + PySide6 GUI，扫描总线、读写全部寄存器、位置控制、波特率/恢复出厂、xdat EEPROM 备份。

> 协议寄存器细节见 [SCS0009 协议内存表](../../../AmazingHandControl/docs/zh-hans/scs_servo_protocol.md)。
> Arduino/扩展接线见 [Arduino Nano](../07-arduino/arduino-nano.md)。

## 一、TTL 调试：组装、ID 与中位

首先，下载"[灵巧手调试.zip](https://juxitech.feishu.cn/wiki/QjYBwL0A0iJVlNkEpUUclLYGnBc)"压缩包，解压后可通过"使用arduio程序调试灵巧手过程（TTL舵机）"文档进行舵机ID设置、标定、校准中位及演示程序运行，或 参考[官方开源代码](https://github.com/pollen-robotics/AmazingHand/tree/main/ArduinoExample)。

## 二、SCS0009 调试工具

适用于 Windows 10 / 11；Linux 与 macOS 的差异见[第 8 节](#8-linux-与-macos-差异)。本教程覆盖从环境安装到完整调试的每一步。

> ⚠️ **兼容性说明：本工具目前仅支持 Feetech SCS0009 舵机**（SCS 系列，电位器位置反馈，10 位分辨率 0–1023）。寄存器表、xdat 参数格式均针对飞特 SCS0009 设计，其他品牌/型号不保证兼容。

### 1. 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | >= 3.8 | 建议 3.10+，从 [python.org](https://www.python.org/downloads/) 下载 |
| PySide6 | >= 6.0 | GUI 框架 |
| pyserial | >= 3.5 | 串口通信 |
| 系统 | Win10 / Win11 | 任意版本 |

### 2. 安装 Python

1. 访问 <https://www.python.org/downloads/>
2. 下载 Python 3.10+ 安装包
3. 安装时**务必勾选 "Add Python to PATH"**(否则命令行找不到 python)

验证安装:

```bash
python --version
```

### 3. 安装依赖

推荐在虚拟环境中安装,避免污染系统 Python:

```bash
# 进入项目目录
cd SCS0009_ServoController

# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境(Windows)
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

> ⚠️ **虚拟环境只需创建一次**。重复执行会覆盖原环境（清空已装依赖）。之后每次只需 `activate` 激活即可。

> 提示:激活后命令行前缀会出现 `(.venv)`。

### 4. 检查环境

```bash
python setup.py
```

看到 `[OK] 环境检查通过，可以运行项目` 即表示环境正确。

### 5. 连接硬件

1. 将 USB 转串口适配器(如 CH340 / CP2102)插入电脑
2. 连接舵机控制器(机械臂控制板)
3. 给舵机供电(建议 DC 5V 5A,Pro 版 DC 12V 5A)

打开设备管理器(`Win+X` → 设备管理器)确认串口号:

```
端口 (COM 和 LPT)
  └─ USB-SERIAL CH340 (COM3)     ← 你的舵机串口
```

> **记下 COM 号**,启动程序时选择。

### 6. 启动 GUI

```bash
python -m src.gui.factory_calibration_tool
```

或手动指定端口(串口被占用时):

```bash
python -m src.gui.factory_calibration_tool --port COM3
```

查看可用端口:

```bash
python -m src.gui.factory_calibration_tool --list-ports
```

### 7. 界面操作流程

> 界面为单面板布局,窗口高度不足时自动出现滚动条,最大化时自适应拉伸。

#### 7.1 串口连接

- 选择端口、波特率(默认 1M),点击 **连接**
- 状态显示 `🟢 已连接`

#### 7.2 扫描舵机

- 点击 **扫描舵机**,检测 ID 1-254 在线舵机
- 扫描结果实时显示在舵机列表(带型号)
- 点击舵机列表某行 → 自动填充到舵机下拉框

#### 7.3 参数读写

- **读取参数**:读取全部 44 个寄存器(EEPROM + SRAM),日志实时显示结果
- **参数表**:5 列展示(地址/寄存器/值/存储区域/读写),EPROM/SRAM/DEFAULT 颜色区分
- **点选联动**:点击参数表某行 → 自动填充"写入地址""长度""值"
- **写入**:修改值后点写入,程序自动解锁/写入/锁定
- **写入结果弹窗**:成功弹绿色提示"✅ 已成功写入",失败弹红色提示"❌ 写入失败"(含原因)

#### 7.4 修改舵机 ID

1. **总线上只接这一只待改 ID 的舵机**，避免与已有 ID 冲突。
2. 在参数表中找到“舵机 ID”（地址 `0x05`）行并选中。
3. 把“值”改为目标 ID，点 **✏️ 写入**；程序会自动解锁 → 写入 → 重新锁定。
4. 改完重新扫描总线确认。右手用 1–8，左手用 11–18。

#### 7.5 位置控制

1. 拖动滑块或直接输入目标位置（0–1023），数值框与滑块同步。
2. 点 **▶ 移动**，状态栏显示“移动中…”。
3. 到位后提示“已移动完成，请关闭力矩”，点 **⏹ 力矩关**。

#### 7.6 波特率/恢复出厂

- **修改波特率**：选择新波特率（38400–1000000 bps）后写入；程序会切换串口波特率并 ping 验证，失败自动回滚。
- **恢复出厂**：恢复为出厂默认（ID=1，波特率 1M），之后需重新扫描。

#### 7.7 xdat 参数（仅保存 EEPROM）

1. `💾 保存当前舵机`:保存当前 ID 舵机的 EEPROM 参数到 xdat 文件(备份)
2. `📂 打开 xdat`:加载备份文件
3. `📤 恢复参数到舵机`:把备份写回舵机

### 8. Linux 与 macOS 差异

#### Linux

- **字体**：`sudo apt install fonts-noto-cjk fonts-noto-color-emoji`，否则中文界面可能空白、emoji 显示为方块。
- **串口权限**：`sudo usermod -a -G dialout $USER`，注销并重新登录后生效；`groups` 应包含 `dialout`。临时可用 `sudo chmod 666 /dev/ttyUSB0`。
- **设备名**：`/dev/ttyUSB*`（CH340 / CP2102 / PL2303）或 `/dev/ttyACM*`（板载 USB 串口）；用 `lsusb`、`dmesg | grep -i tty` 查制造商。
- **固定设备名（可选）**：在 `/etc/udev/rules.d/99-servo.rules` 写 `SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="7523", SYMLINK+="ttyServo"`，之后用 `/dev/ttyServo`。
- **启动**：`python -m src.gui.factory_calibration_tool --port /dev/ttyUSB0`。
- **常见问题**：`pip` 报 externally-managed-environment 时用 venv，或加 `--break-system-packages`。

#### macOS

- **Python**：建议用 Homebrew 安装 `brew install python`，不要用系统自带旧版本。
- **串口命名**：使用 `/dev/cu.*`，不要用 `/dev/tty.*`（后者可能阻塞）；`ls /dev/cu.*` 查看。
- **USB 驱动**：CH340 / CP2102 / FTDI 多数免驱；老批次 CH340 需装 WCH 驱动，可用 `system_profiler SPUSBDataType` 排查。
- **启动**：`python -m src.gui.factory_calibration_tool --port /dev/cu.usbserial-0001`。
- **Apple Silicon**：用原生 Python 3.10+，避免 Rosetta 下的旧 Python；首次运行若提示“无法验证开发者”，到“隐私与安全性”中允许。
- **省电**：macOS 休眠可能断开串口，操作时保持唤醒。

### 9. 注意事项

1. **写入会持久化**：参数写入 EEPROM 后原值被覆盖，无法撤销；修改前先用 xdat 备份。
2. **供电稳定**：供电不足会导致丢步、通信失败或舵机失联；按 [SCS0009 接线与供电](../01-hardware/scs0009.md) 的要求供电。
3. **串口独占**：同一端口不能被两个程序同时打开；使用前关闭串口监视器、上位机等其他占用程序。
4. **ID 修改风险**：总线上只接一只待改 ID 的舵机；若改后失联，可尝试“恢复出厂设置”（ID 回到 1）。
5. **过温/过压**：工具会监控电压和温度（温度 > 60 °C 告警）；持续高温时停机散热。
6. **热插拔**：拔掉 USB 后程序会尝试重连；重新插回后点刷新端口。
7. **Windows 控制台乱码**：命令行工具出现 emoji 乱码时，设置 `PYTHONIOENCODING=utf-8` 后再运行。

### 10. 常见问题

| 问题 | 解决 |
|------|------|
| 找不到串口 | 设备管理器检查驱动;换 USB 口;装 CH340 驱动 |
| 串口被占用 | 关闭串口监视器等程序;重启工具 |
| 中文字体显示空白 | 系统默认微软雅黑,若异常安装中文字体 |
| 舵机扫描不到 | 检查供电/接线;确认波特率 1M |
| 写入失败 | 检查舵机供电与连接;确认目标寄存器可写 |
| PermissionError 打开串口失败 | 确保没有其他进程占用该 COM 口 |
| Linux：`Permission denied: /dev/ttyUSB0` | 未加入 `dialout` 组；见上文 Linux 小节 |
| macOS：串口名带 `tty.` 时卡住 | 改用对应的 `/dev/cu.*` 设备 |
