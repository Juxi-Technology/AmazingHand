# SCS0009 배선, ID와 전원 공급

SCS0009 버전은 Feetech 시리얼 버스 서보 8개를 사용하며, PC/라즈베리 파이가 USB 버스 드라이버 보드를 통해 직접 제어합니다.

## 하드웨어 목록

| 항목 | 사양 |
|------|------|
| 서보 | Feetech SCS0009 시리얼 버스 서보 ×8 |
| 드라이버 보드 | USB 시리얼 버스 드라이버 보드(또는 Arduino + Feetech TTL Linker) |
| 전원 | 7–12V(DC5521)를 드라이버 보드에 입력하고, 드라이버 보드가 서보에 전원 공급; 드라이버 보드와 공통 접지 |
| 통신 | 1,000,000 보드레이트 |

## 서보 ID와 손가락 대응

| 손가락 | 오른손 ID | 왼손 ID |
|------|---------|---------|
| 약지 | 5, 6 | 11, 12 |
| 중지 | 3, 4 | 13, 14 |
| 검지 | 1, 2 | 15, 16 |
| 엄지 | 7, 8 | 17, 18 |

- **홀수 ID**는 손가락마다 첫 번째 서보, **짝수 ID**는 두 번째 서보입니다; 두 번째 서보는 반대로 장착되므로 변환 시 부호를 반대로 합니다.
- 두 서보는 나란히, 축 중심이 일직선으로 장착됩니다: **같은 방향 회전은 측면 벌림, 반대 방향 회전은 굴곡/신전을 생성**하므로 손가락 하나의 자유도 2개를 이 한 쌍의 서보가 함께 만들어냅니다.
- 왼손은 9–16이 아니라 **11–18**이며, "약지 우선" 순서로 번호가 매겨집니다.
- 물리적 방향: 오른쪽에서 왼쪽으로 세어 오른쪽이 홀수, 왼쪽이 짝수입니다. 오른손 중간 위치 순서(raw 0–1023) `451,571,451,571,451,571,451,571`; 왼손 `571,451,571,451,571,451,571,451`.

## 배선

1. 서보 8개를 ID 순서대로 직렬 연결해 버스 드라이버 보드에 연결합니다.
2. 드라이버 보드 USB를 PC 또는 라즈베리 파이에 연결합니다; Linux에서는 사용자를 `dialout` 그룹에 추가해야 합니다.
3. 외부 7–12V 전원을 드라이버 보드의 전원 입력에 연결합니다(서보 3P 선에 직접 연결하지 마세요). **반드시 드라이버 보드와 공통 접지**해야 합니다.
4. 왼손/오른손은 서로 다른 ID 그룹(오른손 1–8, 왼손 11–18)을 사용하며 같은 버스에 연결할 수 있습니다; 제어할 때 "제어 대상"으로 전환합니다.

## 최초 전원 투입

- 조립 전에 로봇 손을 중간 위치에 두고, 중간 위치 기준으로 서보 혼을 장착합니다.
- 최초 연결 시 [SCS0009 디버깅 도구](../06-servo-tuning/scs0009.md)로 ID를 하나씩 스캔하고 중간 위치와 방향을 점검하는 것을 권장합니다.
- 그다음 [데스크톱 GUI/CLI](../04-desktop/scs0009.md) 또는 [웹 제어](../03-web-control/scs0009.md)로 전체 테스트를 진행합니다.
