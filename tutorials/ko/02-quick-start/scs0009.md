# SCS0009 빠른 시작

SCS0009 버스 서보 버전을 받은 사용자가 최대한 빨리 손을 움직이게 하는 데 적합합니다. 전체 설명은 각 장의 링크를 참고하세요.

## 1. 배선

- SCS0009 서보 8개를 ID에 맞춰 버스 드라이버 보드에 연결합니다; 오른손 1–8, 왼손 11–18.
- USB 버스 드라이버 보드를 PC에 연결합니다; 외부 7–12V 전원을 드라이버 보드 전원 입력에 연결하고(서보 3P 선에 직접 연결하지 마세요), 드라이버 보드와 공통 접지합니다.
- 상세 배선, ID와 중간 위치 순서: [SCS0009 배선, ID와 전원 공급](../01-hardware/scs0009.md).

## 2. 서보 점검

[SCS0009 디버깅 도구](../06-servo-tuning/scs0009.md) 또는 [데스크톱 GUI/CLI](../04-desktop/scs0009.md) 사용:

1. 버스를 스캔해 ID 8개를 모두 찾을 수 있는지 확인합니다.
2. 중간 위치, 방향, 제한을 하나씩 점검하고 필요하면 서보 혼 또는 중간 위치를 조정합니다.
3. 모든 서보가 90° / 중간 위치로 부드럽게 이동할 수 있는지 확인합니다.

## 3. 제어 방식 선택

| 방식 | 적합 | 경로 |
|------|------|------|
| 웹 제어 | 슬라이더, 프리셋 포즈 19개, 카메라 텔레오퍼레이션 | [SCS0009 웹 제어](../03-web-control/scs0009.md) |
| 데스크톱 GUI / CLI | 캘리브레이션, 포즈 관리, 시퀀스, 텔레메트리 | [SCS0009 GUI와 CLI](../04-desktop/scs0009.md) |
| 공식 dora Demo | 카메라 → MuJoCo IK → 실제 손 | [SCS0009 손 추적](../05-hand-tracking/scs0009.md) |

## 4. 웹 제어 최단 경로

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

<http://localhost:8000>을 열고 드라이버에서 **SCS0009 버스**를 선택한 뒤 시리얼 포트를 골라 연결합니다; 처음 연결하면 자동으로 중간 위치로 복귀합니다.

## 5. 최초 동작

1. 먼저 "전체 중간 위치로"를 눌러 손이 중간 위치에 있고 이상음/걸림이 없는지 확인합니다.
2. 손가락별 슬라이더를 드래그해 방향을 하나씩 확인합니다.
3. 그다음 "펼치기 / 주먹 쥐기" 등 프리셋 포즈를 시도합니다.
4. 문제가 있으면 먼저 [SCS0009 디버깅과 캘리브레이션](../06-servo-tuning/scs0009.md)과 [FAQ](../08-faq/faq.md)를 확인하세요.
