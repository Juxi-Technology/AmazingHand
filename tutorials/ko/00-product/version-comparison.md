# SCS0009와 PWM 버전 비교 및 선택

AmazingHand의 로봇 손 구조는 동일하지만 두 가지 서보 방식이 있습니다. 선택은 주로 **위치 피드백, 정밀 각도 제어, 데이터 수집**이 필요한지에 달려 있습니다.

## 빠른 결론

- **SCS0009 선택**: 위치/온도/전압 읽기, 정밀 각도, SO-ARM101 로봇 팔에 연결해 LeRobot 데이터 수집 및 학습이 필요할 때.
- **PWM 선택**: 독립 데모, 제스처 상호작용, 웹/데스크톱 빠른 시작이 필요하고 피드백이 필요 없을 때.
- **혼용 금지**: 두 하드웨어는 동시에 한 세트만 연결하며, 전원, 프로토콜, 펌웨어가 모두 다릅니다.

## 전체 비교

| 비교 항목 | SCS0009 시리얼 버스 버전 | PWM 서보 버전 |
|--------|--------------------|------------|
| 추천 이유 | 정밀 각도 제어 + 데이터 읽기; SO-ARM101 로봇 팔에 연결해 LeRobot 데이터 수집 및 학습 가능 | 독립 데모, 제스처 상호작용, 빠른 시작 |
| 서보 모델 | Feetech SCS0009 시리얼 버스 서보 ×8 | PTK 7452 MG-D **디지털** PWM 서보 ×8 |
| 서보 사양 | 2.3 kg·cm@6V, 300° 제어 가능, 0.293° 정밀도 | 4.5 kg·cm@7.4V(이 방식은 5V 공급 시 약 2.8–3 kg·cm), 180°±10°, 333 Hz 갱신 |
| 위치/온도/전압/속도 피드백 | ✅ 읽기 지원 | ❌ 읽기 없음, 걸림이나 탈조 감지 불가 |
| 메인 컨트롤러 | 온보드 없음; PC/라즈베리 파이가 버스 드라이버 보드를 통해 직접 연결 | ESP32-S3 온보드 펌웨어 |
| 허브 | 서보 드라이버 보드 + 9채널 시리얼 버스 허브 | PWM 어댑터 보드(3P 핀 헤더 8개 + 5V/GND) |
| 전원 | 7–12V(DC5521) 드라이버 보드 입력, 서보 정격 6V급 | 5V / 3A 이상, 어댑터 보드와 ESP32는 반드시 공통 접지 |
| 보드레이트 | **1,000,000** | 서보에는 보드레이트 없음; 호스트 PC↔ESP32 시리얼 **115200 8N1** |
| 서보 ID | 반드시 설정: 오른손 1–8, 왼손 11–18 | ID 설정 없음; 고정 채널 CH1–CH8(검지 1/2, 중지 3/4, 약지 5/6, 엄지 7/8), 좌우 손 배선 동일 |
| 통신 링크 | 호스트 PC → 드라이버 보드 → 버스 → 서보 8개 | 호스트 PC → USB 시리얼 115200 → ESP32 → PWM 8채널 |
| 명령 형식 | Feetech 버스 프로토콜, 각도 직접 전송 | 바이너리 프레임: `0x01–0x0A / 0x0C` 제스처, `0xF0` 직접 구동, `0xF1` 왼손/오른손, `0x00` NOP, `0xFE` 반복, `0xFF` 정지 |
| 펌웨어 | 없음(플래싱 불필요) | ESP-IDF 컴파일 필요, 또는 사전 빌드된 `amazinghand_pwm.bin` 직접 플래싱 |
| 왼손/오른손 | 서보 ID가 다름(오른손 1–8, 왼손 11–18) | 동일한 채널 그룹, 코드 매핑 + `0xF1`로 방향 선택 |
| 토크 해제 | 토크 켜기/해제 지원 | 지원하지 않음; E-stop은 제스처만 중단하고 서보는 계속 전원이 들어온 채 위치 유지 |
| 속도 제어 | 속도 파라미터 지원 | 직접 구동 프레임에는 속도 파라미터 없음 |

## SCS0009 버전 요점

- 각 서보에는 고유 ID가 있습니다; 오른손 1–8, 왼손 11–18이며, 배선/서보 교체 후에는 반드시 ID를 다시 설정해야 합니다.
- 시리얼 버스를 사용하며 위치, 속도, 전압, 온도 읽기를 지원해 폐루프 제어와 데이터 수집에 적합합니다.
- PC/라즈베리 파이가 USB 버스 드라이버 보드를 통해 직접 제어하므로 추가 MCU 펌웨어가 필요 없습니다.
- 전원은 7–12V를 버스 드라이버 보드에 입력하며(서보는 6V급), 드라이버 보드와 공통 접지에 주의하세요.
- SO-ARM101, LeRobot 등 관절 피드백이 필요한 학습 흐름에 연결하기 적합합니다.

## PWM 버전 요점

- **PTK 7452 MG-D 디지털 서보**(333 Hz, 500–2500 µs)를 사용하며, SG90 같은 50 Hz 아날로그 서보로 직접 대체할 수 없습니다.
- 서보 정격은 4.5 kg·cm@7.4V이며, 이 방식은 5V/3A로 공급하므로 실제 토크는 약 2.8–3 kg·cm입니다.
- ESP32-S3가 PWM 8채널을 생성하고, 호스트 PC는 USB 시리얼 115200으로 명령만 보내면 됩니다.
- 위치 피드백이 없어 각도, 온도, 전압을 읽을 수 없고 걸림/탈조도 감지할 수 없습니다.
- 왼손/오른손이 동일한 채널 그룹을 공유하며, 손가락마다 한 쌍의 서보 중 오른쪽이 홀수, 왼쪽이 짝수이고 검지는 항상 CH1/2입니다.
- 펌웨어 플래싱이 필요하며, 저장소에서 사전 빌드된 bin을 제공하고 ESP-IDF로 컴파일할 수도 있습니다.
- 독립 데모, 제스처 상호작용, 웹/데스크톱 빠른 시작에 적합하며, 피드백에 의존하는 LeRobot 학습에는 적합하지 않습니다.
