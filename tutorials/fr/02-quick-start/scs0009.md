# Démarrage rapide SCS0009

Pour ceux qui disposent déjà de la version à servos à bus SCS0009 et veulent faire bouger la main au plus vite. Les explications complètes sont dans les liens de chaque chapitre.

## 1. Câblage

- Connectez les 8 servos SCS0009 à la carte de commande de bus selon leur ID ; main droite 1–8, main gauche 11–18.
- Reliez la carte de commande de bus USB à l'ordinateur ; connectez l'alimentation externe 7–12V à l'entrée d'alimentation de la carte (pas directement aux câbles 3P des servos) et assurez la masse commune avec la carte.
- Câblage détaillé, ID et ordre des positions médianes : [Câblage, ID et alimentation SCS0009](../01-hardware/scs0009.md).

## 2. Vérifier les servos

Utilisez l'[outil de débogage SCS0009](../06-servo-tuning/scs0009.md) ou la [GUI/CLI de bureau](../04-desktop/scs0009.md) :

1. Scannez le bus et vérifiez que les 8 ID sont détectés.
2. Vérifiez un par un la position médiane, le sens et les butées ; ajustez si nécessaire le palonnier ou la position médiane.
3. Vérifiez que tous les servos se déplacent en douceur jusqu'à 90° / la position médiane.

## 3. Choisir le mode de contrôle

| Mode | Adapté à | Entrée |
|------|------|------|
| Contrôle web | Curseurs, 19 poses prédéfinies, téléopération caméra | [Contrôle web SCS0009](../03-web-control/scs0009.md) |
| GUI / CLI de bureau | Calibration, gestion des poses, séquences, télémétrie | [GUI et CLI SCS0009](../04-desktop/scs0009.md) |
| Démo dora officielle | Caméra → IK MuJoCo → main réelle | [Suivi de main SCS0009](../05-hand-tracking/scs0009.md) |

## 4. Chemin le plus court pour le contrôle web

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

Ouvrez <http://localhost:8000>, choisissez le driver **Bus SCS0009**, sélectionnez le port série et connectez-vous ; la première connexion ramène automatiquement la main en position médiane.

## 5. Premier mouvement

1. Cliquez d'abord sur le retour au milieu et vérifiez que la main est en position médiane, sans bruit anormal ni point dur.
2. Faites glisser les curseurs doigt par doigt pour vérifier les sens un à un.
3. Essayez ensuite les poses prédéfinies « ouvrir / poing ».
4. En cas de problème, consultez d'abord [Débogage et calibration SCS0009](../06-servo-tuning/scs0009.md) et la [FAQ](../08-faq/faq.md).
