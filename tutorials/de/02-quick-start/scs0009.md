# SCS0009-Schnellstart

Geeignet für Nutzer, die bereits die SCS0009-Bus-Servo-Version haben und die Hand so schnell wie möglich in Bewegung bringen wollen. Vollständige Erläuterungen findest du über die Links der einzelnen Kapitel.

## 1. Verkabelung

- Die 8 SCS0009-Servos nach ID an die Bus-Treiberplatine anschließen; rechte Hand 1–8, linke Hand 11–18.
- USB-Bus-Treiberplatine mit dem PC verbinden; externe 7–12-V-Stromversorgung an den Stromeingang der Treiberplatine (nicht direkt an die 3P-Leitung der Servos) und gemeinsame Masse mit der Treiberplatine.
- Detaillierte Verkabelung, IDs und Mittelstellungsreihenfolge: [SCS0009-Verkabelung, IDs und Stromversorgung](../01-hardware/scs0009.md).

## 2. Servos prüfen

Verwende das [SCS0009-Debugging-Werkzeug](../06-servo-tuning/scs0009.md) oder die [Desktop-GUI/CLI](../04-desktop/scs0009.md):

1. Bus scannen und bestätigen, dass alle 8 IDs gefunden werden.
2. Mittelstellung, Richtung und Endanschläge einzeln prüfen; bei Bedarf Servohorn oder Mittelstellung anpassen.
3. Bestätigen, dass alle Servos sanft auf 90° / Mittelstellung fahren.

## 3. Steuerungsart wählen

| Art | Geeignet für | Einstieg |
|------|------|------|
| Websteuerung | Schieberegler, 19 Preset-Posen, Kamera-Teleop | [SCS0009-Websteuerung](../03-web-control/scs0009.md) |
| Desktop-GUI / CLI | Kalibrierung, Posenverwaltung, Sequenzen, Telemetrie | [SCS0009 GUI und CLI](../04-desktop/scs0009.md) |
| Offizielles dora-Demo | Kamera → MuJoCo IK → echte Hand | [SCS0009-Handtracking](../05-hand-tracking/scs0009.md) |

## 4. Kürzester Weg zur Websteuerung

```bash
cd Amazinghand-web
pip install -r requirements.txt
python server.py --no-connect
```

Öffne <http://localhost:8000>, wähle als Treiber **SCS0009 bus**, wähle die serielle Schnittstelle und verbinde; bei der ersten Verbindung wird automatisch in die Mittelstellung gefahren.

## 5. Erste Bewegung

1. Zuerst „Alle zentrieren" anklicken und bestätigen, dass die Hand in der Mittelstellung ist und keine ungewöhnlichen Geräusche/Klemmer auftreten.
2. Den Schieberegler eines einzelnen Fingers ziehen und die Richtung einzeln prüfen.
3. Dann Preset-Posen wie „Öffnen / Faust" ausprobieren.
4. Bei Problemen zuerst [SCS0009-Debugging und Kalibrierung](../06-servo-tuning/scs0009.md) und die [FAQ](../08-faq/faq.md) ansehen.
